# E04 — Implicit Functions and Regular Level Sets

## 全集框架

- 核心问题：给定一组光滑方程 h(x) = c，怎样不手工构造 chart，就能证明它的解集是光滑流形，并知道维数？
- 受众起点：已学过光滑流形、chart、转移映射、光滑映射（E02），以及反函数定理的陈述与证明、导数作为线性近似、Jacobian、链式法则、方向导数 d/dt F(x+tv)|₀（E03）。具备线性代数中秩、可逆矩阵、行列式的基本知识，但"行秩 = 列秩"在本集现场复习。
- 主线：手造 chart 的困难 → 圆上"能不能解出 y"的局部问题 → 线性版本：可逆块决定可解性 → 由反函数定理推出隐函数定理（完整证明）→ 导数公式 → 正则值 → 正则水平集定理（完整证明，chart 由方程自动产生）→ 球面实例 → 条件必要性与定理的单向性 → 衔接切空间。

### c01-why-equations — 为什么要让方程替我们造 chart

- question：观众能说出"手造 chart"在矩阵流形上为什么行不通，以及本集要建立的那条推理链（反函数定理 → 隐函数定理 → 正则水平集定理）。
- requires：smooth-manifold（e02），inverse-function-theorem（e03）。
- music：motivation
- teaching_sequence：
  - 直觉：球面 S² 很容易画出 chart（半球投影、球极投影）。O(3) = {R : RᵀR = I} 在 ℝ⁹ 里，是 9 个变量满足 6 个方程，没有可以画出来的"半球"。
  - 定义：回顾 E02 的光滑流形要求每点都有 chart，并且转移映射光滑。逐个构造 chart、证明它们覆盖全集、再验证转移映射，在高维时不可操作。
  - 例子：并排展示两个对象：S² 上的六个半球 chart（可画）与写成方程 RᵀR = I 的 O(3)（只有方程）。
  - 边界：方程本身不保证解集是流形。例如 x² − y² = 0 是两条交叉直线，交点处不像任何 ℝᵈ。所以需要一个条件，c08 会回到这里。
  - 用途：给出本集路线图：IFT → ImplicitFT → 正则水平集定理。最终把"发明一套 atlas"换成两步机械计算：对方程求导，然后检查秩。
- proof_steps：无
- necessity：预告交叉直线 x² − y² = 0：方程光滑，解集却不是流形，所以必须有附加条件。这里只提出问题，c08 完整论证。

### c02-circle-and-linear — 圆上的局部求解与线性版本

- question：观众能指出在圆的哪些点上可以把 y 解成 x 的函数、哪些点不行，并说明可解性由"被解变量那一块导数是否可逆"决定；在线性情形下能写出解 y = −B⁻¹Ax。
- requires：derivative（e03）。
- music：definition
- teaching_sequence：
  - 直觉：f(x, y) = x² + y² − 1。在 (a, b) 且 b > 0 附近，圆就是 y = √(1 − x²) 的图像；b < 0 时是 y = −√(1 − x²)。整个圆不是任何单一函数 y(x) 的图像（每个 |x| < 1 都对应两个 y），但局部可以。
  - 定义（局部可解）：存在开集 A ∋ a、B ∋ b，使得在盒子 A × B 内，f(x, y) = 0 ⇔ y = g(x)。
  - 例子 1：在 (1, 0) 附近，任意小的盒子中，x 略小于 1 时有两个 y（±√(1−x²)），x > 1 时没有 y，所以不是 x 的函数。此处 ∂f/∂y = 2y = 0。但 ∂f/∂x = 2x = 2 ≠ 0，换成解 x = √(1 − y²) 就可以。解哪个变量是一个选择，由导数决定。
  - 例子 2（线性版本）：f(x, y) = Ax + By，其中 A ∈ ℝᵏˣᵈ，B ∈ ℝᵏˣᵏ。方程 Ax + By = 0 对每个 x 都有唯一解 y ⇔ B 可逆，此时 y = −B⁻¹Ax。若 B 不可逆：ker B ≠ {0}，于是任一解加上 ker B 中的非零向量仍是解，解不唯一；同时 range B ≠ ℝᵏ，当 Ax ∉ range B 时无解。
  - 边界：非线性 f 在 (a, b) 附近 ≈ D_x f(a,b)(x − a) + D_y f(a,b)(y − b)，扮演 A、B 的分别是 D_x f 和 D_y f。线性近似只在附近可信，所以结论只能是局部的。把"线性情形成立"推广到"非线性情形局部成立"，正是反函数定理的工作。
  - 用途：给出隐函数定理需要的条件 D_y f(a, b) 可逆，并预告导数公式 Dg = −[D_y f]⁻¹ D_x f 就是线性解 −B⁻¹A。
- proof_steps：
  1. 线性情形，B 可逆时：Ax + By = 0 ⇔ By = −Ax ⇔ y = −B⁻¹Ax。存在性与唯一性同时成立。
  2. 线性情形，B 不可逆时：取 0 ≠ w ∈ ker B。若 (x, y) 是解，则 A x + B(y + w) = Ax + By = 0，(x, y + w) 也是解，所以不唯一。又由秩–零化度，dim range B < k；取 x = 0 时 y = 0 是解，但对使 Ax ∉ range B 的 x 无解（这样的 x 是否存在取决于 A，所以说"可能无解"）。
- necessity：在点 (1, 0)：∂f/∂y = 0，对应线性版本中 B = 0（1×1）不可逆。动画展示该点附近的盒子内，左半边每条竖线与圆交两次，右半边与圆不交，正好是线性版本中"不唯一 / 无解"的两种失败方式。

### c03-ift-proof — 由反函数定理推出隐函数定理

- question：观众能复述证明的四个动作：构造 F(x, y) = (x, f(x, y))；验证 DF 可逆；利用 F⁻¹ 的第一分量是恒等映射；令 g(u) = Y(u, 0) 并证明双向等价。同时能解释为什么要人为补上第一分量 x。
- requires：inverse-function-theorem（e03），invertible-block（受众已知，本章复述），local-graph 直观（c02）。
- music：proof
- teaching_sequence：
  - 直觉：反函数定理只处理"n 个方程、n 个未知数"。我们手上是 k 个方程、d + k 个未知数，方程比未知数少 d 个。办法是把自由变量 x 原封不动地抄一份当作额外的 d 个"方程"，凑成方阵。
  - 定义（定理陈述，L3 Thm 2）：U ⊆ ℝᵈ⁺ᵏ 开，f : U → ℝᵏ 光滑，f(a, b) = 0，D_y f(a, b) ∈ ℝᵏˣᵏ 可逆。则存在开集 A ∋ a、B ∋ b，以及唯一的光滑映射 g : A → B，使得对 (x, y) ∈ A × B：f(x, y) = 0 ⇔ y = g(x)。
  - 例子：贯穿全章用圆 f = x² + y² − 1 在 p = (0.6, 0.8) 处作为可视化实例（d = k = 1，D_y f = 1.6 ≠ 0）。
  - 边界：结论是局部的，只在 A × B 内成立。D_y f 不可逆时，构造的 F 的 Jacobian 退化，反函数定理无法使用（对应 c02 中的 (1, 0)）。
  - 用途：正则水平集定理的证明（c06）直接调用本定理来产生 chart。
- proof_steps：
  1. 构造。定义 F : U → ℝᵈ⁺ᵏ，F(x, y) = (x, f(x, y))。F 光滑，因为两个分量都光滑。F(a, b) = (a, f(a, b)) = (a, 0)。
  2. 求导。DF(a, b) = [[I_d, 0], [D_x f(a, b), D_y f(a, b)]]。第一行块：第一分量 x 对 x 的导数是 I_d，对 y 的导数是 0。第二行块是 f 的偏导数。
  3. 可逆性。分块下三角矩阵的行列式等于对角块行列式之积：det DF(a, b) = det I_d · det D_y f(a, b) = det D_y f(a, b) ≠ 0。所以 DF(a, b) 可逆。
  4. 调用反函数定理。存在开集 U₀ ∋ (a, b)、V₀ ∋ (a, 0)，使 F|_{U₀} : U₀ → V₀ 是微分同胚。记其逆 F⁻¹(u, v) = (X(u, v), Y(u, v))，X、Y 光滑。
  5. 第一分量不变。对 (u, v) ∈ V₀，令 (x, y) = F⁻¹(u, v)，则 (u, v) = F(x, y) = (x, f(x, y))，比较第一分量得 x = u，即 X(u, v) = u，所以 F⁻¹(u, v) = (u, Y(u, v))。
  6. 定义 g。令 A₀ = {u ∈ ℝᵈ : (u, 0) ∈ V₀}，它是开集，因为 u ↦ (u, 0) 连续，A₀ 是开集 V₀ 的原像，且 a ∈ A₀。定义 g(u) = Y(u, 0)，它是光滑映射 Y 与光滑映射 u ↦ (u, 0) 的复合，所以光滑。g(a) = b，因为 F⁻¹(a, 0) = (a, b)。
  7. (⇐) g 的图像落在解集里。对 u ∈ A₀，F⁻¹(u, 0) = (u, g(u)) ∈ U₀。两边作用 F：(u, 0) = F(u, g(u)) = (u, f(u, g(u)))，所以 f(u, g(u)) = 0。
  8. (⇒) 解集附近都在图像上。设 (x, y) ∈ U₀ 且 f(x, y) = 0。则 F(x, y) = (x, 0) ∈ V₀，所以 x ∈ A₀。又 F(x, g(x)) = (x, 0)（第 7 步），且 F 在 U₀ 上单射，所以 (x, y) = (x, g(x))，即 y = g(x)。
  9. 化成盒子形式。取开盒 A₁ × B ⊆ U₀，包含 (a, b)。令 A = A₁ ∩ A₀ ∩ g⁻¹(B)，它是开集（g 连续），且含 a。对 (x, y) ∈ A × B，第 7、8 步给出 f(x, y) = 0 ⇔ y = g(x)。唯一性：若 g̃ 也满足结论，则 (x, g̃(x)) 是解，由第 8 步得 g̃(x) = g(x)。
- necessity：
  - 若 D_y f(a, b) 奇异，第 3 步 det DF = 0，第 4 步无法调用反函数定理。圆在 (1, 0) 时 DF = [[1, 0], [2, 0]]，第二列全零：F 把竖直方向压扁。画面显示该点附近的小方格经 F 变成一条线段（与 E03 中"奇异线性映射把圆盘压成线段"呼应）。
  - 为什么必须补上第一分量 x：若只用 f : ℝᵈ⁺ᵏ → ℝᵏ，它不是方阵映射，"可逆"无从谈起。补上 x 后，F 既是方阵映射，又让 F⁻¹ 的第一分量保持为 x，于是"x 自由、y 被决定"的结构被保留下来。这一步是整个证明的关键设计。
- visual_events（句子级）：

### c04-implicit-derivative — 不解出 g，也能求它的导数

- question：观众能推导 Dg(x) = −[D_y f(x, g(x))]⁻¹ D_x f(x, g(x))，并在圆上验证它与直接求导的结果一致。
- requires：implicit-function-theorem（c03），链式法则（e03）。
- music：proof
- teaching_sequence：
  - 直觉：g 一般没有显式公式，但 f(x, g(x)) ≡ 0 是一个恒等式。恒等式两边可以同时求导。
  - 定义：Dg = −[D_y f]⁻¹ D_x f，即 c02 中线性解 −B⁻¹A 在每一点的版本。
  - 例子：圆上 g(x) = √(1 − x²)，直接求导得 g'(x) = −x/√(1 − x²) = −x/y。由公式：D_x f = 2x，D_y f = 2y，g' = −(2y)⁻¹·2x = −x/y，两者一致。在 p = (0.6, 0.8) 处，g' = −0.75。
  - 边界：公式要求 D_y f(x, g(x)) 可逆，而不仅仅在 (a, b) 处可逆。由连续性（f 是 C¹，det 连续），det D_y f 在 (a, b) 附近保持非零，必要时缩小 A 即可。
  - 用途：c06、E05 中图像参数化 ψ(x) = (x, g(x)) 的导数 Dψ = (I, Dg) 会用到。
- proof_steps：
  1. 对 x ∈ A 有 f(x, g(x)) = 0。令 Φ(x) = (x, g(x))，则 f ∘ Φ ≡ 0。
  2. 链式法则：D(f ∘ Φ)(x) = Df(Φ(x)) · DΦ(x) = [D_x f, D_y f] · [[I_d], [Dg(x)]] = D_x f + D_y f · Dg(x)。
  3. 恒等于 0 的函数导数为 0：D_x f(x, g(x)) + D_y f(x, g(x)) · Dg(x) = 0。
  4. 连续性：det D_y f(x, g(x)) 是 x 的连续函数，在 a 处非零，所以在 a 的某邻域内非零（缩小 A）。左乘 [D_y f]⁻¹ 得 Dg(x) = −[D_y f(x, g(x))]⁻¹ D_x f(x, g(x))。
- necessity：在 (1, 0) 处 D_y f = 0，公式给出 −x/y = −1/0，发散。动画中切线随点移向 (1, 0) 越来越陡，最后竖直，"作为 x 的函数的斜率"无界。这正对应 g 在该点不存在。
- visual_events：
  - e1｜"g 通常写不出来，但恒等式写得出来"｜公式 f(x, g(x)) ≡ 0，以及圆与绿色图像弧｜"≡" 闪烁｜—｜公式停在顶部
  - e2｜"两边对 x 求导"｜链式法则展开：[D_x f  D_y f] 乘以列块 [I; Dg]｜行块与列块对齐相乘，乘积展开为 D_x f + D_y f·Dg｜—｜展开式 "= 0"
  - e3｜"把 D_y f 移过去"｜最终公式 Dg = −[D_y f]⁻¹ D_x f 加框｜旁边的线性版本 y = −B⁻¹Ax 中 B⁻¹A 与之用虚线连接｜—｜两公式并列
  - e4｜"在圆上检验"｜点 p = (0.6, 0.8) 处的切线（橙色）；计算面板 g' = −x/y = −0.6/0.8 = −0.75｜切线以斜率 −0.75 画出，面板逐行出现｜—｜切线与数值
  - e5｜"直接求导也得到同样结果"｜面板第二列：d/dx √(1 − x²) = −x/√(1 − x²) = −0.75｜两列数值相同，打勾｜—｜两列并列
  - e6｜"把点推向 (1, 0)"｜点沿圆移动，切线随之旋转；右上角斜率读数实时变化 −0.75 → −3 → −10 → ∞｜在 (1, 0) 切线竖直，读数变为 "−1/0"，红色｜—｜竖直切线
- outcome_check：给出曲线 x³ + y³ = 2 在 (1, 1) 处，观众能用公式算出 dy/dx = −x²/y² = −1。
- source：L3 Part III 末尾；HW p8（公式书写，本集给出正确形式 D_x f + D_y f·Dg = 0）；RU 9.28 式 (58)

### c05-regular-value — 正则值：在每一点都满秩

- question：观众能陈述正则值的定义，能把"Dh(x) 满射"翻译为"rank Dh(x) = k"，并理解为什么秩为 k 就能选出 k 个独立列、重排坐标后套用隐函数定理。
- requires：derivative（e03），row-column-rank（受众已知，本章复述）。
- music：definition
- teaching_sequence：
  - 直觉：隐函数定理需要"某个 k×k 块可逆"。秩为 k 的 k×n 矩阵一定藏着这样一个块，只是不一定在最后 k 列。
  - 定义（L3 Def 6）：h : U ⊆ ℝⁿ → ℝᵏ 光滑。c ∈ ℝᵏ 是正则值，若对每个 x ∈ h⁻¹(c)，Dh(x) : ℝⁿ → ℝᵏ 满射，等价地 rank Dh(x) = k。条件是对 h⁻¹(c) 中的所有点，"某一点满秩"不够。
  - 例子：h(x, y) = x² + y²，Dh = [2x, 2y]。在 c = 1 的水平集上 (x, y) ≠ 0，所以 rank = 1，1 是正则值。c = 0 时 h⁻¹(0) = {0}，Dh(0) = [0, 0]，0 不是正则值。
  - 边界：正则值是 h 与 c 共同的性质，不是集合本身的性质（c08 中 (xᵀx − 1)² 的例子会说明）。若 h⁻¹(c) = ∅，条件空真成立，c 也算正则值。
  - 用途：c06 中，每一点的满秩条件让我们在每一点都能选出可逆块，于是每一点都有 chart。
- proof_steps：
  1. 满射 ⇔ 秩 k：Dh(x) 的像是 ℝᵏ 的子空间，维数等于 rank，所以像等于 ℝᵏ ⇔ rank = k。
  2. 引理（行秩 = 列秩 ⇒ k 个独立列）：k×n 矩阵 J 秩为 k，则列空间维数 = 行秩 = k。n 个列向量张成这个 k 维空间，任何张成组中都含一组基，所以存在 k 个线性无关列，对应的 k×k 子矩阵可逆。
  3. 重排坐标：设这 k 列的下标为 i₁, …, i_k。坐标置换 P : ℝⁿ → ℝⁿ 把它们移到最后 k 个位置。P 是线性同构（光滑，逆也光滑），所以在 P 下考察集合，不改变"是否为光滑子流形"与维数。置换后写成 p = (a, b)，a ∈ ℝⁿ⁻ᵏ，b ∈ ℝᵏ，D_y h(a, b) 可逆。
- necessity：
  - 只在某一点满秩不够：h(x, y) = x² − y²，c = 0。在 (1, 1) 处 Dh = [2, −2] 满秩，但在 (0, 0) ∈ h⁻¹(0) 处 Dh = 0。由于原点那一点的存在，集合整体不是流形（c08 证明）。
  - 不能固定"最后 k 列"：圆在 (1, 0) 时最后一列（∂/∂y）为 0，但第一列非零。正因为可以选列，才能覆盖整个圆。
- visual_events：
  - e1｜"隐函数定理要的是一个可逆块"｜k×n 矩阵网格（k = 2, n = 5 示意），最后两列描金框｜金框闪烁｜—｜矩阵居中
  - e2｜"但可逆块不一定在最后"｜具体数值矩阵 [[1, 0, 2, 0, 0], [0, 1, 1, 0, 0]]，最后两列全零，标红｜红框出现，标注 "singular"｜—｜红色最后两列
  - e3｜"秩为 2，所以一定有 2 列线性无关"｜列向量以箭头形式画到 ℝ² 平面（5 个箭头，其中 2 个为零向量）｜两条独立箭头（第 1、2 列）高亮成金色｜矩阵上移｜ℝ² 中两条金箭头
  - e4｜"把这两列换到最后"｜矩阵列置换动画：第 1、2 列滑到第 4、5 位，坐标标签 x₁…x₅ 随列移动｜列交换｜—｜置换后矩阵，最后两列为单位阵，金框
  - e5｜"正则值：在解集的每一点都满秩"｜定义卡：c regular ⟺ ∀x ∈ h⁻¹(c): rank Dh(x) = k，"∀" 用红色强调｜定义逐项出现｜—｜定义卡进入账本
  - e6｜"例子：圆是正则水平集，原点不是"｜左：x² + y² = 1，圆上任一点的 Dh 箭头（法向，非零）；右：x² + y² = 0 只有一个点，Dh = 0（箭头长度为 0，红点）｜两图并列淡入｜—｜左绿勾，右红叉
  - e7｜"一个坏点就足以破坏"｜x² − y² = 0 的交叉线，沿线一个探针点移动，旁边读数 rank Dh 始终显示 1，到原点时变为 0（红）｜探针移动｜—｜原点红色脉冲
- outcome_check：给出 h(x, y, z) = (x² + y² + z², z)，c = (1, 0)，观众能写出 Dh，并判断在水平集（赤道圆）上 rank = 2，所以 c 是正则值。
- source：L3 Part IV Def 6、Thm 3 证明开头；HW p8；BD（Regular Value 板书）

### c06-level-set-theorem — 正则水平集定理：方程自己长出 chart

- question：观众能完整复述证明：在任一点重排坐标 → 隐函数定理给出图像 → 投影就是 chart、图像参数化就是它的逆 → 维数 n − k → 转移映射光滑。并说出"这个定理替我们省掉了什么"。
- requires：implicit-function-theorem（c03），regular-value 与引理（c05），smooth-manifold / chart / transition-map（e02）。
- music：proof
- teaching_sequence：
  - 直觉：在每一点，隐函数定理说"M 局部是 n − k 个自由变量的光滑函数的图像"。图像天然有坐标：自由变量本身。所以 chart 就是"忘掉被解出的变量"。
  - 定义（L3 Thm 3）：U ⊆ ℝⁿ 开，h : U → ℝᵏ 光滑，c 是正则值，则 M = h⁻¹(c) 是 ℝⁿ 的 n − k 维光滑嵌入子流形。
  - 例子：圆（n = 2, k = 1）得到 1 维流形；chart 正是 c02 中四色弧上的投影 (x, y) ↦ x 或 (x, y) ↦ y，与 E02 中 S¹ 的 chart 完全相同，但这次是定理产出的，不是猜出来的。
  - 边界：结论是"嵌入"子流形：拓扑取 ℝⁿ 的子空间拓扑（自动 Hausdorff、第二可数）。维数 n − k 恰好是"未知数个数减去独立方程个数"。
  - 用途：c07 球面、E05 中 O(n) 都直接调用本定理。E05 求切空间时会复用这里的图像参数化 ψ。
- proof_steps：
  1. 拓扑前提：M ⊆ ℝⁿ 取子空间拓扑。ℝⁿ 是 Hausdorff、第二可数的度量空间，子空间继承这两条性质。
  2. 固定 p ∈ M。由正则性，rank Dh(p) = k。由 c05 引理，重排坐标后写成 p = (a, b)，x ∈ ℝⁿ⁻ᵏ，y ∈ ℝᵏ，D_y h(a, b) 可逆。
  3. 令 f(x, y) = h(x, y) − c。则 f(a, b) = 0，D_y f = D_y h 在 (a, b) 处可逆。由隐函数定理，得开集 A ∋ a、B ∋ b 与光滑 g : A → B，使 M ∩ (A × B) = {(x, g(x)) : x ∈ A}。
  4. 定义 ψ : A → M，ψ(x) = (x, g(x))（光滑，作为到 ℝⁿ 的映射）；定义 φ : M ∩ (A × B) → A，φ(x, y) = x（线性投影的限制，连续）。W := M ∩ (A × B) 是 M 中的开集，因为 A × B 在 ℝⁿ 中开。
  5. 互为逆：φ(ψ(x)) = φ(x, g(x)) = x。若 (x, y) ∈ W，由第 3 步 y = g(x)，所以 ψ(φ(x, y)) = ψ(x) = (x, g(x)) = (x, y)。φ 与 ψ 都连续，所以 φ : W → A 是到 ℝⁿ⁻ᵏ 开子集的同胚，即一个 chart。
  6. 维数：chart 取值于 ℝⁿ⁻ᵏ，p 任意，所以 M 是 n − k 维拓扑流形。
  7. 转移映射光滑：设 (W₁, φ₁)、(W₂, φ₂) 是这样构造的两个 chart（可能使用不同的坐标重排），φᵢ = πᵢ|_{Wᵢ}，其中 πᵢ 是到某 n − k 个坐标的线性投影，φ₁⁻¹ = ψ₁。在 φ₁(W₁ ∩ W₂) 上（开集，因为 φ₁ 是同胚且 W₁ ∩ W₂ 在 M 中开），φ₂ ∘ φ₁⁻¹ = π₂ ∘ ψ₁，是线性映射与光滑映射的复合，所以光滑。对称地，φ₁ ∘ φ₂⁻¹ 也光滑。于是这些 chart 构成光滑图册，M 是光滑流形。
  8. 嵌入：每个 chart 的逆 ψ 是到 ℝⁿ 的光滑映射，Dψ = [[I], [Dg]] 单射，且 M 带子空间拓扑。这正是嵌入子流形的含义。
  9. 收获：没有猜任何 chart。方程 h = c 加上秩检查，迫使 chart 存在，并给出了构造方法。
- necessity：
  - 第 2 步需要每一点满秩：交叉点 (0, 0) 处无法选出可逆列，第 3 步无从开始，结论也确实失败（c08）。
  - 第 7 步说明为什么不用担心"不同点用了不同的坐标重排"：转移映射总是"投影 ∘ 光滑参数化"，自动光滑。这是 E02 中"相容性"要求的自动满足。

### c07-sphere — 球面：一次求导，零个 chart

- question：观众能独立用"方向导数法"求出 Dh(x)[v] = 2xᵀv，判断 1 是正则值，并得出 dim Sⁿ⁻¹ = n − 1。
- requires：regular-level-set-theorem（c06），directional-derivative（e03）。
- music：definition
- teaching_sequence：
  - 直觉：c02 中的圆推广到任意维数。
  - 定义：Sⁿ⁻¹ = {x ∈ ℝⁿ : xᵀx = 1} = h⁻¹(1)，h(x) = xᵀx，k = 1。
  - 例子：h(x + tv) = xᵀx + 2t xᵀv + t² vᵀv，所以 Dh(x)[v] = d/dt h(x + tv)|_{t=0} = 2xᵀv。在球面上 x ≠ 0，取 v = x 得 Dh(x)[x] = 2 ≠ 0，所以 Dh(x) 是非零线性泛函，秩 1，满射到 ℝ。由定理，Sⁿ⁻¹ 是 n − 1 维嵌入子流形。
  - 边界：在 S² 的赤道点，h 对 x₃ 的偏导 2x₃ = 0，所以不能解 x₃，但能解 x₁ 或 x₂。这与圆上 (1, 0) 的情况相同，c05 中"选列"的自由在这里用上。
  - 用途：方向导数法同样适用于矩阵变量，E05 中的 O(n) 用同样三步：展开、取一次项、检查满射。
- proof_steps：
  1. 展开：h(x + tv) = (x + tv)ᵀ(x + tv) = xᵀx + 2t xᵀv + t² vᵀv。
  2. 求导：Dh(x)[v] = d/dt|_{t=0} = 2xᵀv。
  3. 满射：x ∈ Sⁿ⁻¹ ⇒ x ≠ 0 ⇒ Dh(x)[x/2 · s] = s·|x|² = s，对任意 s ∈ ℝ，所以满射（rank 1）。
  4. 结论：1 是正则值，Sⁿ⁻¹ 是 n − 1 维光滑嵌入子流形。
- necessity：同一个 h 取 c = 0：h⁻¹(0) = {0}，Dh(0) = 0，不是正则值；集合是一个点（0 维），而不是定理所说的 n − 1 维。取 c = −1 得空集（空真正则）。
- visual_events：
  - e1｜"把圆推广到任意维"｜S²（n = 3 可视化）线框球，标签 Sⁿ⁻¹ = {xᵀx = 1}｜球淡入｜—｜球居中
  - e2｜"只需对 h 求一次方向导数"｜公式三行：展开、取 t 的一次项系数、Dh(x)[v] = 2xᵀv｜逐行出现，t 的一次项高亮｜—｜结果加框
  - e3｜"在球面上 x 不为零"｜球面上一点 x，以及从原点出发的径向箭头（非零）｜箭头描出｜—｜标注 "rank 1"
  - e4｜"所以 1 是正则值，球面是 n − 1 维流形"｜结论卡｜卡片飞入账本｜—｜—
  - e5｜"不同区域解出不同坐标"｜S² 上着色：|x₃| 较大的区域（北、南）着绿色"解 x₃"，|x₁| 较大着蓝色，|x₂| 较大着紫色｜颜色随区域铺开；赤道上一点的 2x₃ = 0 标签闪红，随后该点颜色为蓝｜—｜三色球面
- outcome_check：给出椭球 h(x) = x₁² + 4x₂² + 9x₃²，c = 1，观众能写出 Dh(x)[v] = 2x₁v₁ + 8x₂v₂ + 18x₃v₃，并说明它在椭球上非零。
- source：L3 Part V 后 "Running example: the sphere"；HW p5（外蕴视角，此处写正确形式 S² ⊆ ℝ³）

### c08-when-regularity-fails — 正则性去掉之后：交叉、尖点，以及定理的单向性

- question：观众能用具体例子说明：(1) 不正则的点可能真的不是流形（交叉）；(2) 可能是拓扑流形但不是光滑嵌入子流形（尖点）；(3) 也可能仍然是流形，因为定理只是充分条件（(xᵀx − 1)²）。并知道正则水平集可以是空集或不连通。
- requires：regular-level-set-theorem（c06），topological-manifold 与 homeomorphism（e01、e02），sphere-level-set（c07）。
- music：counterexample
- teaching_sequence：
  - 直觉：用一族水平集 h(x, y) = x² − y² = c，让 c 从 1 连续滑到 −1。c ≠ 0 时都是双曲线（正则，两条分支）；只有 c = 0 时变成交叉的两条直线。坏事只发生在不正则的那一个水平。
  - 定义：无新定义。
  - 例子 1（交叉，c = 0）：Dh = (2x, −2y)，在 (0, 0) 处为 0。它不是 1 维拓扑流形：若原点有一个邻域同胚于开区间，可取一个连通的小邻域 N ⊆ 交叉集；N 去掉原点后至少分成 4 个连通分支（四条臂互不相连）。而一个开区间去掉一点恰好分成 2 个连通分支。同胚保持"去掉一点后的连通分支数"，矛盾。
  - 例子 2（尖点）：h(x, y) = y² − x³，c = 0。Dh = (−3x², 2y)，在 (0, 0) 处为 0。
    - 它是拓扑流形：集合等于 {(x, y) : x = (y²)^{1/3}}，是 x = |y|^{2/3} 在整个 y 轴上的图像。(x, y) ↦ y 是它到 ℝ 的同胚（连续函数图像与定义域同胚）。
    - 它不是光滑嵌入子流形。采用以下事实（本集陈述，不证明）：1 维嵌入子流形在每一点附近有导数非零的光滑参数化 γ。若原点处有这样的 γ，γ(0) = 0，γ'(0) ≠ 0：曲线上 x ≥ 0，所以 x(t) 在 t = 0 取最小值，x'(0) = 0，从而 y'(0) ≠ 0。由一维反函数定理，y(t) 在 0 附近可逆，于是 x 是 y 的光滑函数 x(γ(y⁻¹(·)))，在 0 处可微。但曲线上 x = |y|^{2/3}，在 y = 0 处不可微（斜率趋于无穷），矛盾。
    - 对比：γ(t) = (t², t³) 是光滑参数化，像正好是尖点，但 γ'(0) = 0。"能被光滑曲线扫出来"不等于"光滑子流形"，参数化必须是正则的。
  - 例子 3（单向性）：h(x) = (xᵀx − 1)²，c = 0。h⁻¹(0) = Sⁿ⁻¹，是流形。但 Dh(x)[v] = 2(xᵀx − 1)·2xᵀv = 0 在球面上处处成立，所以 0 不是正则值。定理不适用，结论却成立。定理是充分条件，不是必要条件；正则性是"方程"的性质，不仅是"集合"的性质。
  - 例子 4：c = 1 时 x² − y² = 1 是正则水平集，但有两条分支（不连通的 1 维流形）。h(x) = xᵀx 取 c = −1 得空集，空真正则。定理不承诺连通，也不承诺非空。
  - 边界：交叉点处 Dh = 0，于是 rank 0 < k = 1；尖点同理。所有失效都发生在秩下降的点上。
  - 用途：E05 中求切空间时，(xᵀx − 1)² 再次出现：它的 ker Dh = ℝⁿ 比真正的切空间大，说明 T_pM = ker Dh(p) 也需要正则性。
- proof_steps：
  1. 交叉不是拓扑流形：见例子 1 的连通分支计数论证。
  2. 尖点是拓扑流形：(x, y) ↦ y 连续，其逆 y ↦ (|y|^{2/3}, y) 连续，二者互逆。
  3. 尖点不是光滑嵌入子流形：见例子 2，在"嵌入子流形局部有正则参数化"这一事实下的反证。
  4. (xᵀx − 1)² 的导数：链式法则 Dh(x)[v] = 2(xᵀx − 1) · D(xᵀx)[v] = 2(xᵀx − 1) · 2xᵀv，在 xᵀx = 1 时为 0。
- necessity：本章即必要性一章。核心信息：去掉正则性后，结论可能完全失败（交叉），可能部分失败（尖点：拓扑上可以，光滑上不行），也可能碰巧成立（平方后的球面）。所以不能把定理当作"当且仅当"使用。
- visual_events：
  - e1｜"让水平值 c 连续变化"｜3D 马鞍面 z = x² − y²（半透明），水平切面 z = c｜c 从 1.0 平滑降到 −1.0 再回到 0｜—｜切面在 z = 0 停住
  - e2｜"c 不为零时都是双曲线"｜俯视 2D：c = 1 的两条分支（绿），c = −1 的两条分支（绿，旋转 90°）｜随 c 变化实时绘制，c ≠ 0 时右上角显示 "regular ✓"｜—｜—
