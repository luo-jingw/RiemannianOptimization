# E03 — The Inverse Function Theorem

## 全集框架

- 核心问题：一个映射在某点的导数可逆，凭什么就能断定它在该点附近是光滑可逆的？这个结论的每个条件为什么都不能去掉？它为什么是后面"由方程制造 chart"的引擎？
- 受众起点：已知度量空间、开集、开球、连续（E01）；已知光滑映射、微分同胚，并知道手工构造 chart 困难（E02）。上过本课，见过反函数定理的陈述，但不清楚它为何必要、证明在做什么。
- 主线：手造 chart 太难 → 导数是最佳线性近似 → 反函数定理陈述与图像 → 去掉每个条件会怎样坏 → 压缩映射原理（证明工具）及其条件的必要性 → 反函数定理完整证明（单射 → 像是开集 → 逆可微且 C¹）→ 它买到了什么，以及为何还需要 E04。

## 章节

### c01-why-ift — 我们需要一台"chart 制造机"

- question：为什么一门优化课要停下来证明一个分析定理？
- requires：chart-problem（e02-smooth-manifolds）、diffeomorphism（e02-smooth-manifolds）
- music：motivation
- teaching_sequence：
  - 直觉：E02 结束时我们卡住了。chart 要求局部同胚到 ℝ^d 的开集，并且转移映射光滑。球面还能靠半球投影手画 chart，O(n) 这样 n(n−1)/2 维的矩阵集合就没法手造了。我们需要一种机制，只从"定义方程 + 一次导数计算"就保证 chart 存在。
  - 定义：本集的主角是一个局部定理：如果 F 在一点的线性化可逆，那么 F 在附近就是一个微分同胚。局部微分同胚恰好就是"可以当作坐标变换"的东西。
  - 例子：极坐标 (r,θ) ↦ (r cosθ, r sinθ) 本身就是一个 chart 的逆，它的局部可逆性正来自导数可逆。
  - 边界：本集只处理"n 个方程、n 个未知数"。约束集合通常方程比未知数少，那是 E04 的事。
  - 用途：E04 会用反函数定理推出隐函数定理，再推出正则水平集定理；E05 的 T_pM = ker Dh(p) 和 O(n) 都建在上面。
- proof_steps：无
- necessity：先给出全集的"条件清单"预告：C¹、导数在该点可逆、结论只是局部。后面每一项都会配一个反例。
- visual_events：
  - e1｜回顾 E02：球面能手画 chart｜三维单位球、两个半球 chart 投影到平面圆盘｜半球依次高亮并投影｜无｜两个 chart 与它们的重叠区停留
  - e2｜"O(n) 的 chart 无法手造"｜右侧出现一个 3×3 矩阵 R 与方程 RᵀR = I，周围一团抽象的高维点云示意｜点云旋转，上方打出问号；标签"示意：高维集合无法画出"｜球面缩小到左上角｜点云与问号
  - e3｜"我们需要一台机器"｜中央流程框：方程 h(x)=c ＋ 一次导数计算 → [机器] → chart｜框体依次出现，机器内部标"反函数定理"｜点云淡出｜流程框
  - e4｜引出全系列依赖链｜依赖链横条：IFT → 隐函数定理 → 正则水平集 → T_pM = ker Dh → O(n)｜IFT 节点高亮，其余灰显｜流程框缩小到顶部｜依赖链常驻顶部窄条，作为本集"路标"
- outcome_check：观众能说出：反函数定理的作用是从导数信息中"制造"局部坐标，而不是计算某个具体的逆。
- source：L3 §1.3 "The problem"、L3 §2；HW p9（IFT → ImplicitFT → 正则水平集链条）
- next：要理解"导数可逆"在说什么，先要把导数看成一个线性映射。

### c02-derivative-as-linear-map — 导数是最佳线性近似

- question：多元函数的导数到底是什么对象？怎样计算它在某个方向上的作用？
- requires：continuity（e01-topology）、linear-invertibility（受众已知）
- music：definition
- teaching_sequence：
  - 直觉：把一张弯曲的网格不断放大，它看起来越来越像一个平行四边形网格，也就是线性映射的像。导数就是"放大到极限时看到的那个线性映射"。
  - 定义：F: U⊆ℝⁿ→ℝᵐ 在 x 处可微，指存在线性映射 DF(x) 使得 F(x+h) = F(x) + DF(x)h + r(h)，且 ‖r(h)‖/‖h‖ → 0（记作 o(‖h‖)）。注意余项是 o(‖h‖)，不是 o(‖h‖²)；要求的是"比一次更小"，不是"二阶小"。在标准基下 DF(x) 就是雅可比矩阵 (∂F_i/∂x_j)。F 是 C¹ 指 x ↦ DF(x) 连续。
  - 方向导数技巧：DF(x)[v] = d/dt F(x+tv)|_{t=0}。证明：F(x+tv) = F(x) + t·DF(x)v + o(|t|)，除以 t 后令 t→0。这是整个系列计算导数的标准方法（E04 球面、E05 O(n) 都用它）。
  - 例子：h(x) = xᵀx。h(x+tv) = xᵀx + 2t xᵀv + t² vᵀv，所以 Dh(x)[v] = 2xᵀv，不需要写出任何偏导数。
  - 链式法则：D(G∘F)(x) = DG(F(x))·DF(x)，即"线性化的复合等于复合的线性化"。
  - 算子范数：‖A‖ = sup_{‖h‖≤1} ‖Ah‖，因此 ‖Ah‖ ≤ ‖A‖‖h‖。后面证明里所有估计都靠它。
  - 边界：存在全部偏导数不等于可微；本系列遇到的映射都是 C¹ 或光滑的，不展开这个病态情形。
  - 用途：c03 的条件"DF(x₀) 可逆"就是"这个线性映射不压扁任何方向"。
- proof_steps：
  1. 方向导数公式：由定义取 h = tv，F(x+tv) − F(x) = t·DF(x)v + r(tv)，‖r(tv)‖/|t| = ‖v‖·‖r(tv)‖/‖tv‖ → 0（v≠0），所以 (F(x+tv)−F(x))/t → DF(x)v。
  2. h(x)=xᵀx 的展开与求导，如上。
- necessity：o(‖h‖) 这个条件决定了"线性近似是唯一的"。如果允许余项和 ‖h‖ 同阶，任何线性映射都可以算作"近似"。动画用两个候选线性映射对比：只有正确的那个，误差与 ‖h‖ 之比趋于 0。
- visual_events：
  - e1｜"放大弯曲网格"｜左：定义域正方形网格；右：映射 F(u,v) = (u + 0.3 sin v, v + 0.3 u²) 的像，是一张弯曲网格；一个小方框标出 F(x)｜相机推近小方框，右侧弯曲网格逐渐变直｜依赖链路标｜放大后右侧近似平行四边形网格
  - e2｜"这个线性映射就是 DF(x)"｜在放大视图上叠加 DF(x) 作用于单位方格得到的平行四边形（虚线）｜两者重合度随放大增加，旁边数值显示 ‖r(h)‖/‖h‖ 随 ‖h‖ 减小而趋于 0｜放大视图｜公式 F(x+h)=F(x)+DF(x)h+o(‖h‖) 停留在上方
  - e3｜"错误的线性映射"｜叠加第二个平行四边形（另一个矩阵 B）｜同样显示 ‖F(x+h)−F(x)−Bh‖/‖h‖，它趋于一个正常数而不是 0｜正确映射仍在｜两条比值曲线并排：一条趋于 0，一条趋于常数
  - e4｜方向导数技巧｜点 x 处一条直线 t ↦ x+tv（定义域），其像曲线 t ↦ F(x+tv)，以及像曲线在 t=0 的切向量｜切向量箭头标注 DF(x)[v] = d/dt F(x+tv)\|₀｜e2 的公式缩到右侧台账｜台账：①最佳线性近似 ②方向导数公式
  - e5｜例子 h(x)=xᵀx｜KaTeX 逐行展开：(x+tv)ᵀ(x+tv) = xᵀx + 2t xᵀv + t² vᵀv → 一次项系数 2xᵀv 被高亮框住｜无｜台账加 ③ Dh(x)[v]=2xᵀv
  - e6｜链式法则｜三个平面 x → F(x) → G(F(x))，两个线性化平行四边形依次复合｜D(G∘F)=DG·DF 标注｜台账压缩为 3 条｜台账：①最佳线性近似 ②方向导数 ③链式法则；算子范数一行公式出现在台账底部
- outcome_check：观众能不写偏导数，直接用 d/dt F(x+tv)|₀ 求出 xᵀx 的导数；并能说出余项为何必须是 o(‖h‖)。
- source：L3 §2.2（F(x₀+h)=F(x₀)+DF(x₀)h+o(‖h‖)）；L3 §7 球面计算；HW p6（笔记中余项误写为 o(‖h‖²)）；RU p.220

### c03-ift-statement — 定理陈述与图像

- question：反函数定理究竟断言什么？"导数可逆"在几何上排除了什么？
- requires：best-linear-approx、jacobian（e03-c02），diffeomorphism（e02-smooth-manifolds），open-set（e01-topology）
- music：definition
- teaching_sequence：
  - 直觉：线性映射可逆时，它既不把方向压扁成更低维，也不把两个方向折到一起。反函数定理说的是：这种一阶的非退化性在一个足够小的邻域里一直保持。
  - 定义（L3 Thm 1）：设 U⊆ℝⁿ 开，F: U→ℝⁿ 为 C¹，x₀∈U。若 DF(x₀) 可逆，则存在开邻域 U₀∋x₀、V₀∋F(x₀)，使 F|_{U₀}: U₀→V₀ 是双射、其逆 C¹（即 F|_{U₀} 是 C¹ 微分同胚），并且 D(F⁻¹)(F(x₀)) = [DF(x₀)]⁻¹。若 F 是 C^k 或光滑的，局部逆也是 C^k 或光滑的。
  - 拆解结论：三件事：(1) 局部单射；(2) 像 V₀ 是开集，即 F(x₀) 附近每个点都被取到；(3) 逆可微，且导数是导数的逆。
  - 例子：线性映射 F(x)=Ax 的情形，A 可逆时 F⁻¹(y)=A⁻¹y，结论是全局的。定理把它推广到非线性映射，代价是只成立于局部。
  - 边界：结论只是局部的（c04 用极坐标说明）；导数公式本身可以由链式法则从 F⁻¹∘F = id 得到，但前提是已经知道 F⁻¹ 可微。可微性才是定理的真正内容（c04 用 x³ 说明）。
  - 用途：c07–c09 证明它；E04 用它证明隐函数定理。
- proof_steps：
  1. 导数公式的推导（假定逆可微）：g(F(x)) = x 对 x∈U₀ 成立，两边求导，由链式法则 Dg(F(x₀))·DF(x₀) = I，所以 Dg(F(x₀)) = [DF(x₀)]⁻¹。强调这一步依赖于"g 可微"这个尚未证明的事实。
- necessity：奇异线性映射的图像：矩阵 [[1,0],[0,0]] 把圆盘压成线段，不同的点被压到同一点，线段以外的点一个也取不到。可逆性同时排除了"不单射"和"不满射到邻域"两种失败。
- visual_events：
  - e1｜"小团被变形成小团"｜左：x₀ 周围的小圆盘 U₀（带网格）；右：F(x₀) 周围的像区域 V₀｜F 的动画：网格从左平滑变形到右，不撕裂、不折叠；用 c02 的同一个 F｜依赖链路标｜两团并列，中间双向箭头 F 与 F⁻¹
  - e2｜定理陈述｜KaTeX 定理框出现在上方，三项结论逐条出现，每条出现时在图上高亮对应元素：单射（两点不重合）、V₀ 开（V₀ 边界虚线，内部点全被覆盖）、逆可微（反向箭头）｜两团保持｜定理框停留
  - e3｜"可逆排除了什么"｜下方小面板：单位圆盘经 [[1,0],[0,0]] 被压成线段｜动画压扁，两点合为一点的动画特写；线段外一个点标"取不到"｜上方两团缩小｜奇异映射面板与非奇异两团并排
  - e4｜导数公式与链式法则｜F⁻¹∘F = id 的图（U₀ → V₀ → U₀ 回到原点），公式 Dg(F(x₀))DF(x₀)=I 推出｜"前提：g 可微"用橙色标出｜定理框缩到右侧台账｜台账：①IFT 三项结论 ②导数公式需要 g 可微
- outcome_check：观众能分别说出 IFT 的三项结论，并指出导数公式本身不是定理难点。
- source：L3 §2.1 Theorem 1、§2.2 Picture；HW p6；BD（da20 号照片：IFT 板书）；RU 9.24

### c04-ift-necessity — 去掉条件会怎样坏

- question：C¹、导数可逆、"局部"这三点，各自去掉后结论如何失败？
- requires：ift-statement（e03-c03）
- music：counterexample
- teaching_sequence：
  - 直觉：四个反例分别打破四件事：逆的可微性、局部单射、全局单射、导数连续性。
  - 例子 1，x³ 在 0 处：F(x)=x³ 是 ℝ 上的光滑双射，逆 F⁻¹(y)=y^{1/3} 也连续，所以 F 是同胚。但 F'(0)=0 不可逆，F⁻¹ 在 0 处不可微（切线竖直）。结论：导数可逆不是"逆存在"的必要条件，却是"逆可微"的必要条件。证明：若 g 在 0 可微且 g(x³)=x，求导得 g'(0)·F'(0) = 1，但 F'(0)=0，矛盾。
  - 例子 2，x² 在 0 处：F'(0)=0。任何邻域 (−ε,ε) 内 F(ε/2)=F(−ε/2)，不单射；并且负数不在像中，F(0)=0 不是像的内点。导数不可逆时，单射和"像是开集"都可能失败。二维版本 (x,y)↦(x²,y) 把平面沿 y 轴对折。
  - 例子 3，极坐标 F(r,θ) = (r cosθ, r sinθ)，定义在 (0,∞)×ℝ：DF = [[cosθ, −r sinθ],[sinθ, r cosθ]]，det DF = r > 0，处处可逆。但 F(r,θ) = F(r,θ+2π)，全局不单射。结论：导数处处可逆只给出局部微分同胚，不给出全局逆。这正是"结论是局部"的必要性，也说明为什么流形需要多个 chart。
  - 例子 4，F(x) = x + 2x² sin(1/x)，F(0)=0：F'(0) = lim_{h→0}(h + 2h² sin(1/h))/h = 1 ≠ 0，在 0 处可逆；但 x≠0 时 F'(x) = 1 + 4x sin(1/x) − 2 cos(1/x)。在 x_k = 1/(2kπ) 处 F'(x_k) = −1 < 0，在 y_k = 1/((2k+1)π) 处 F'(y_k) = 3 > 0。任意邻域都同时含有导数为负和为正的点，所以 F 在任何邻域都不单调；区间上的连续单射必严格单调，因此 F 在 0 的任何邻域上都不单射。失败原因：F' 在 0 处不连续，"在一点可逆"不能扩散到邻域。C¹ 条件就是保证一点处的非退化性可以传播到整个邻域。
  - 边界：例子 4 中 F 处处可微，坏的只是导数的连续性；这说明定理中的 C¹ 不是为了方便才加的。
  - 用途：c07 证明的第一步正是"用 F' 的连续性找到一个 F' 一直接近 A 的球"。例子 4 恰好让这一步失败。
- proof_steps：
  1. x³：由链式法则推出矛盾（如上）。
  2. 极坐标：计算 det DF = r cos²θ + r sin²θ = r。
  3. 例子 4：计算 F'(0)、F'(x)，代入 x_k、y_k，引用"区间上连续单射 ⇔ 严格单调"（介值定理，受众已知）。
- necessity：本章即必要性章节。
- visual_events：
  - e1｜反例 1：x³｜二维坐标系，y=x³ 的曲线；镜像（关于 y=x）为 y=x^{1/3}｜两曲线同时绘出；在原点画 x³ 的水平切线（斜率 0），以及 x^{1/3} 的竖直切线（斜率 ∞）｜依赖链路标；右侧台账：IFT 三项结论｜标签"逆存在 ✓ 逆可微 ✗"
  - e2｜反例 2：x²｜y=x² 曲线，一个小区间 (−ε,ε) 在 x 轴上高亮；两点 ±ε/2 被同时映到同一高度｜两条竖线汇合到同一 y 值；y<0 区域标"取不到"｜清空 e1｜接 2D 平面对折动画：网格沿 y 轴折叠｜标签"单射 ✗ 像为开集 ✗"

### c05-contraction-principle — 压缩映射原理

- question：怎样不解方程，就证明一个方程有唯一解？
- requires：metric-space（e01-topology）、continuity（e01-topology）
- music：proof
- teaching_sequence：
  - 直觉：一个把任意两点距离至少按比例 c<1 缩小的映射，会把整个空间往一个点"吸"。反复作用，点之间的距离几何级数地缩小，序列必然聚到一点，这一点就是不动点。证明本身就是一个算法。
  - 定义（RU 9.22）：(X,d) 为度量空间，φ: X→X。若存在 c<1 使 d(φ(x),φ(y)) ≤ c·d(x,y) 对所有 x,y 成立，称 φ 是压缩映射。Cauchy 列：对任意 ε>0，存在 N，当 n,m≥N 时 d(x_n,x_m)<ε。完备：每个 Cauchy 列都在 X 中收敛。ℝⁿ 以及 ℝⁿ 的闭子集都是完备的。
  - 定理（RU 9.23）：X 完备、φ 是压缩，则 φ 有且只有一个不动点。
  - 例子：φ(x) = cos(x)/2 在 ℝ 上：|φ'(x)| ≤ 1/2，是压缩，迭代收敛到 x = cos(x)/2 的唯一解。
  - 边界：c06 讲完备性和 c<1 的必要性。
  - 用途：c07–c08 中，把"解 f(x)=y"改写成"求 φ_y 的不动点"。
- proof_steps：
  1. 唯一性：若 φ(x)=x、φ(y)=y，则 d(x,y) = d(φ(x),φ(y)) ≤ c·d(x,y)；因 c<1，只能 d(x,y)=0。
  2. 构造：任取 x₀，令 x_{n+1} = φ(x_n)。
  3. 相邻距离：d(x_{n+1},x_n) = d(φ(x_n),φ(x_{n−1})) ≤ c·d(x_n,x_{n−1})，归纳得 d(x_{n+1},x_n) ≤ cⁿ d(x₁,x₀)。
  4. 几何级数：n<m 时，由三角不等式 d(x_n,x_m) ≤ Σ_{i=n+1}^{m} d(x_i,x_{i−1}) ≤ (cⁿ + cⁿ⁺¹ + … + c^{m−1}) d(x₁,x₀) ≤ cⁿ/(1−c) · d(x₁,x₀)。
  5. Cauchy：cⁿ → 0，所以 {x_n} 是 Cauchy 列。
  6. 完备性：存在 x∈X 使 x_n → x。
  7. 连续性：压缩映射是（一致）连续的，所以 φ(x) = lim φ(x_n) = lim x_{n+1} = x。
- necessity：见 c06。本章强调第 6 步使用完备性、第 4 步使用 c<1，这两处即后面反例攻击的位置。
- visual_events：
  - e1｜"把空间往一个点吸"｜平面上散布 12 个彩色点，每个点有一条短箭头指向其像（φ 为二维压缩，例如 φ(p) = 0.5·Rot(30°)p + b）｜所有点同时被作用 4 次，点群收缩成一个点；任意两点之间的连线长度标签每次 ×0.5｜依赖链路标｜收缩后的点标为不动点 x*
  - e2｜定义｜KaTeX：d(φ(x),φ(y)) ≤ c·d(x,y)，c<1｜两点及其像的距离对比条｜点群淡出为背景｜定义框
  - e3｜唯一性｜两个假想的不动点 x、y，箭头指向自身｜距离 d 应缩小为 c·d，又要保持 d 不变，两条长度条对比后 d 塌缩为 0｜定义框缩入右侧台账｜台账 ①唯一性
  - e4｜一维蛛网图：迭代｜坐标系，曲线 y = cos(x)/2 与直线 y = x；从 x₀ = 2 出发画蛛网折线｜每一跳对应 x_{n+1}=φ(x_n)；下方一行跳跃长度柱状图，按 cⁿ 缩小｜e1 背景淡出｜蛛网收敛到交点
  - e5｜几何级数界｜柱状图上，把 x_n 之后的所有柱子堆叠，叠加总长 ≤ cⁿ/(1−c)·d(x₁,x₀) 的括号｜KaTeX 逐步写出不等式链｜蛛网保留｜台账加 ②d(x_n,x_m) ≤ cⁿ/(1−c) d(x₁,x₀)
  - e6｜Cauchy → 极限 → 不动点｜数轴上序列点越来越密，"完备"标签指向极限点，然后箭头 φ(x)=x｜依次高亮步骤 5、6、7；第 6 步"完备性"与第 4 步"c<1"用橙色标记｜蛛网缩小｜台账压缩为：①唯一 ②几何界 ③完备 ⇒ 极限存在 ④连续 ⇒ 极限是不动点
- outcome_check：观众能复述证明的四个关键：唯一性、几何级数界、完备性给出极限、连续性说明极限是不动点；并指出完备性和 c<1 各用在哪一步。
- source：RU 9.22、9.23

### c06-contraction-necessity — 完备性与 c<1 为什么不能少

- question：压缩映射原理的两个条件，去掉哪一个都会让不动点消失吗？
- requires：contraction-principle（e03-c05）
- music：counterexample
- teaching_sequence：
  - 直觉：去掉完备性，序列想收敛的地方可能被"挖掉"了；去掉"严格小于 1 的统一比例"，序列可以一直走下去。
  - 例子 1，不完备：X = (0,1]，φ(x) = x/2。φ 把 X 映到 (0,1/2] ⊂ X，且 |φ(x)−φ(y)| = ½|x−y|，是压缩。迭代 1, 1/2, 1/4, … 是 Cauchy 列，但极限 0 ∉ X。不动点只能是 0，所以 X 中没有不动点。证明中坏掉的是第 6 步。
  - 例子 2，c=1：φ(x) = x+1 于 ℝ。|φ(x)−φ(y)| = |x−y|，没有不动点；迭代 x_n = x₀+n 发散。
  - 例子 3，逐对严格缩小但没有统一 c：X = [1,∞)（ℝ 的闭子集，完备），φ(x) = x + 1/x。φ(x) ≥ 2 > 1，所以 φ: X→X。|φ(x)−φ(y)| = |x−y|·|1 − 1/(xy)|，而 xy ≥ 1 ⇒ 0 ≤ 1 − 1/(xy) < 1，所以 x≠y 时 |φ(x)−φ(y)| < |x−y|。但 φ(x) − x = 1/x > 0，没有不动点。原因：比例 1 − 1/(xy) 在 x,y→∞ 时趋于 1，没有统一的 c<1，几何级数界失效。
  - 边界：在本定理的应用（c08）里，完备性来自"闭球 B̄ 是 ℝⁿ 的闭子集"。这就是为什么证明里要用闭球而不是开球。
  - 用途：c08 中会明确指出哪里用了闭球。
- proof_steps：
  1. 例子 1：φ((0,1]) ⊆ (0,1]；x_n = 2^{−n}；Cauchy；若 φ(x)=x 则 x=0 ∉ X。
  2. 例子 3：φ(X)⊆X；|φ(x)−φ(y)| = |x−y|·|1−1/(xy)| < |x−y|（x≠y）；φ(x)−x = 1/x > 0。
- necessity：本章即必要性章节。
- visual_events：
  - e1｜不完备：(0,1] 上 x/2｜数轴 [0,1]，0 处画空心圆并标"挖掉"，序列点 1, ½, ¼, … 向 0 跳跃｜点越跳越密，最后一步跳进空心圆时打叉｜依赖链路标；台账（c05 的 4 条，第 ③ 条闪烁）｜标签"Cauchy ✓ 极限 ∉ X ✗"
  - e2｜c=1：x+1｜数轴，点每次右移 1，长度条不缩小｜点走出画面右侧｜清空 e1｜标签"距离不缩小 ⇒ 无界漂移"
  - e3｜逐对缩小但无统一 c：x+1/x｜蛛网图：y = x + 1/x 与 y = x，两条曲线渐近而不相交；从 x₀=1 出发的蛛网折线一直向右上方延伸｜下方实时显示比例 1 − 1/(x_n x_{n+1})，数值越来越接近 1｜清空 e2｜台账第 ② 条闪烁（几何界失效）
  - e4｜回到 IFT 证明的预告｜一个闭球 B̄（实心边界）对比一个开球（虚线边界）｜标签"闭球 = ℝⁿ 的闭子集 ⇒ 完备"｜清空｜两个球并列停留
- outcome_check：观众能为"完备性"和"c<1"各举一个反例，并说出各自让 c05 证明的哪一步失效。
- source：RU 9.23（证明结构）；三个反例属补充（非笔记内容）

### c07-ift-proof-injective — 证明 (a)：冻结雅可比的牛顿迭代与局部单射

- question：怎样把"解 f(x)=y"写成一个压缩映射的不动点问题，并由此得到 f 在 a 附近单射？
- requires：contraction-principle（e03-c05）、operator-norm、chain-rule（e03-c02）、ift-statement（e03-c03）
- music：proof
- teaching_sequence：
  - 直觉：牛顿法解 f(x)=y 的一步是 x ← x + f'(x)⁻¹(y − f(x))。如果把雅可比冻结在基点 a，用 A = f'(a) 代替 f'(x)，就得到 φ_y(x) = x + A⁻¹(y − f(x))。只要 f' 在附近一直接近 A，这个迭代每步都把误差至少减半。
  - 记号说明：本证明沿用 Rudin 的记号，f 就是我们的 F，a 就是陈述中的 x₀，A = f'(a)。Rudin 证明中出现的"任意点 x₀"，这里改记为 p，避免和基点混淆。
  - 引理（中值不等式，RU 9.19）：若 E 凸，φ 在 E 上可微且 ‖φ'(x)‖ ≤ M，则 ‖φ(x₁) − φ(x₂)‖ ≤ M‖x₁ − x₂‖。证明：设 u = φ(x₁) − φ(x₂)，γ(t) = x₂ + t(x₁ − x₂) ∈ E，s(t) = u·φ(γ(t))。由一元中值定理，s(1) − s(0) = s'(τ) = u·φ'(γ(τ))(x₁ − x₂) ≤ ‖u‖·M‖x₁ − x₂‖；而 s(1) − s(0) = u·u = ‖u‖²，于是 ‖u‖ ≤ M‖x₁ − x₂‖（u = 0 时显然）。
  - 例子：f(u,v) = (u + 0.25v², v + 0.25 sin u)，a = (0,0)，A = I。展示 φ_y 迭代从 x₀ = a 出发解 f(x) = y = (0.3, 0.2)。
  - 用途：c08 用同一个 φ_y 证明 V 是开集，c09 用它的压缩性估计逆的增量。
- proof_steps：
  1. 设 A = f'(a) 可逆，取 λ > 0 使 2λ‖A⁻¹‖ = 1。
  2. f' 在 a 处连续（这里用到 C¹，正是 c04 例子 4 中失败的那一步）：存在以 a 为中心的开球 U ⊆ E，使 x∈U 时 ‖f'(x) − A‖ < λ。
  3. 对每个 y∈ℝⁿ 定义 φ_y(x) = x + A⁻¹(y − f(x))，x∈E。关键观察：f(x) = y ⇔ A⁻¹(y − f(x)) = 0 ⇔ φ_y(x) = x（A⁻¹ 可逆，零向量只有零原像）。解方程等价于找不动点。
  4. φ_y'(x) = I − A⁻¹f'(x) = A⁻¹(A − f'(x))，所以对 x∈U：‖φ_y'(x)‖ ≤ ‖A⁻¹‖·‖A − f'(x)‖ < ‖A⁻¹‖·λ = 1/2。
  5. U 是球，因此是凸集。由中值不等式，对所有 x₁,x₂∈U：‖φ_y(x₁) − φ_y(x₂)‖ ≤ ½‖x₁ − x₂‖。
  6. 由此 φ_y 在 U 中至多有一个不动点（与 c05 唯一性论证相同）。由第 3 步，对每个 y，方程 f(x)=y 在 U 中至多有一个解，即 f 在 U 上单射。
  7. 注意：第 6 步只用到"至多一个"，还没用到完备性，也还没证明解存在。存在性留给 c08。
- necessity：
  - 若不冻结雅可比、每步使用 f'(x)⁻¹，那就是真牛顿法：需要 f'(x) 处处可逆，而这正是待证的东西。冻结在 a 只需要 a 一点的可逆性，加上 f' 的连续性。
  - 常数 ½ 的来源：λ 的选取让 ‖A⁻¹‖λ = ½。任意小于 1 的常数都可以；选 ½ 是为了 c08、c09 中的估计简洁。
- visual_events：
  - e1｜牛顿法到冻结牛顿法｜左：一维图 y = f(x)，从 x_n 画切线交 y 水平线得 x_{n+1}（真牛顿）；然后把所有切线斜率固定为 f'(a)，画平行线迭代（冻结牛顿）｜两组折线对比：真牛顿用不同斜率，冻结版全部平行｜依赖链路标｜冻结版折线保留，标 φ_y(x) = x + A⁻¹(y − f(x))
  - e2｜记号对照｜上方小表：Rudin f = 我们的 F；a = x₀；A = f'(a)；任意点记作 p｜表出现 3 秒后缩入台账顶部｜一维图缩到左侧｜台账：记号行
  - e3｜第 1–2 步：选 λ 和球 U｜二维定义域面板：a 点，球 U（半透明），U 内每点 f'(x) 用一个小平行四边形表示，并与 A 的平行四边形叠合，偏差 < λ 时着绿色｜球半径从大缩小，直到所有平行四边形变绿｜一维图淡出｜台账 ①‖f'(x) − A‖<λ on U，2λ‖A⁻¹‖=1
  - e4｜第 3 步：解方程 = 找不动点｜双面板：定义域（左）与值域（右），右边目标点 y；左边迭代点 x₀=a, x₁, x₂, …，右边对应 f(x_n) 逐步靠近 y｜点逐跳出现，跳跃长度标签每次至少减半｜U 保留｜台账 ②f(x)=y ⇔ φ_y(x)=x
  - e5｜第 4–5 步：‖φ'‖<½ 与中值不等式｜KaTeX 推导 φ_y' = A⁻¹(A − f'(x))，以及范数估计链；旁边插入引理小框：线段 γ(t)、函数 s(t)、中值点 τ｜引理框展开，讲完后折叠为一行｜双面板缩小｜台账 ③‖φ_y(x₁) − φ_y(x₂)‖ ≤ ½‖x₁ − x₂‖
  - e6｜第 6 步：单射｜U 中两个点 x₁ ≠ x₂ 都标"f(x)=y 的解"→ 两者都是 φ_y 的不动点 → 距离应 ≤ ½ 自身 → 矛盾，合并｜动画与 c05 e3 相同风格（复用）｜台账压缩：①②合并为"φ_y 是 U 上的 ½-压缩，不动点 = 解"；新增 ③f 在 U 上单射
  - e7｜还缺什么｜U 的像 f(U) 画在右侧，边界用问号标注："是开集吗？"｜问号闪烁｜台账保持｜过渡到 c08
- outcome_check：观众能写出 φ_y，解释它的不动点为什么就是 f(x)=y 的解，并说出 ‖φ_y'‖<½ 由 λ 的选取保证、C¹ 用在了第 2 步。
- source：RU 9.24 证明 (a) 前半、9.19（中值不等式）；L3 §2（陈述）

### c08-ift-proof-open — 证明 (a) 续：像是开集

- question：为什么 f(a) 附近的每个 y 都在 f(U) 中？
- requires：ift-proof-injective（e03-c07）、contraction-principle 与完备性（e03-c05、c06）
- music：proof
- teaching_sequence：
  - 直觉：取 V 中任一点 y₀ = f(p)，在 p 周围放一个闭球 B̄。只要 y 离 y₀ 足够近，φ_y 就把 B̄ 映回自身。于是压缩映射原理在完备的 B̄ 上给出不动点，也就是 f(x)=y 的解。
  - 例子：沿用 c07 的二维 f；y 在 y₀ 周围半径 λr 的小球内取几处，分别展示迭代在 B̄ 内收敛。
  - 边界：这里第一次用到存在性部分，需要完备性。B̄ 是 ℝⁿ 的闭子集，所以是完备的（c06 e4 的伏笔）。
  - 用途：至此 f: U → V 是双射且 V 开，逆映射 g: V → U 存在。c09 证明它可微。
- proof_steps：
  1. 令 V = f(U)。取 y₀∈V，则 y₀ = f(p)，p∈U。
  2. 取 r > 0，使以 p 为中心、半径 r 的开球 B 的闭包 B̄ ⊆ U（U 开，这样的 r 存在）。
  3. 断言：只要 ‖y − y₀‖ < λr，就有 y∈V。这样 V 包含 y₀ 的一个开球，而 y₀ 任意，所以 V 开。
  4. 固定这样的 y，用 c07 中的 φ = φ_y。估计起点的位移：‖φ(p) − p‖ = ‖A⁻¹(y − f(p))‖ = ‖A⁻¹(y − y₀)‖ ≤ ‖A⁻¹‖·‖y − y₀‖ < ‖A⁻¹‖λr = r/2。
  5. φ 把 B̄ 映进 B̄：对 x∈B̄，‖φ(x) − p‖ ≤ ‖φ(x) − φ(p)‖ + ‖φ(p) − p‖ < ½‖x − p‖ + r/2 ≤ r/2 + r/2 = r。所以 φ(x)∈B ⊆ B̄。（这里用了 c07 第 5 步的 ½-Lipschitz，因为 B̄ ⊆ U。）
  6. B̄ 是 ℝⁿ 的闭子集，因而完备；φ 是 B̄ 上的 ½-压缩。由压缩映射原理，存在 x∈B̄ 使 φ(x) = x，即 f(x) = y。
  7. x∈B̄ ⊆ U，所以 y = f(x)∈f(U) = V。断言得证，V 开。
  8. 合并 c07：f|_U: U → V 是双射，V 开，记逆为 g: V → U。证明 (a) 完成。
- necessity：
  - 若用开球 B 代替 B̄，B 不完备，c06 例子 1 的现象理论上可能出现：迭代序列的极限落在边界上，从而离开定义域。闭球保证极限仍在 U 内。

### c09-ift-proof-derivative — 证明 (b)：逆可微，导数是导数的逆

- question：如何证明 g 可微，而不是只靠链式法则"假定"它可微？
- requires：ift-proof-open（e03-c08）、best-linear-approx、operator-norm（e03-c02）
- music：proof
- teaching_sequence：
  - 直觉：两件事。第一，g 不会放大距离超过一个固定倍数：x 的增量 h 被 y 的增量 k 控制，即 ‖h‖ ≤ λ⁻¹‖k‖。所以 k→0 时 h→0。第二，有了这个控制，f 的线性近似误差可以直接搬运成 g 的线性近似误差。
  - 引理（RU 9.8，扰动下的可逆性）：A 可逆且 ‖B − A‖·‖A⁻¹‖ < 1，则 B 可逆。理由：B = A(I − A⁻¹(A − B))，而 ‖A⁻¹(A − B)‖ < 1，所以 I − A⁻¹(A − B) 由 Neumann 级数 Σ(A⁻¹(A − B))^j 可逆。并且可逆矩阵的集合 Ω 是开集，求逆 B ↦ B⁻¹ 在 Ω 上连续（矩阵元素是原矩阵元素的有理函数，由 Cramer 法则，因而光滑）。
  - 例子：c07 的二维 f，在 V 中某点比较 g 的割线增量与 [f'(g(y))]⁻¹k。
  - 边界：这里只证 C¹；C^k 由归纳得到。
  - 用途：至此定理全部结论成立。c03 中"需要 g 可微"的橙色标记在本章被划掉。
- proof_steps：
  1. 取 y∈V 与 k，使 y + k∈V。令 x = g(y)，x + h = g(y + k)；由单射，k≠0 ⇒ h≠0。
  2. 用同一个 φ = φ_y（任意固定的 y 参数都满足 c07 第 5 步）：φ(x + h) − φ(x) = h + A⁻¹(f(x) − f(x + h)) = h − A⁻¹k。
  3. 由 ½-Lipschitz：‖h − A⁻¹k‖ ≤ ½‖h‖。于是 ‖A⁻¹k‖ ≥ ‖h‖ − ‖h − A⁻¹k‖ ≥ ½‖h‖，所以 ‖h‖ ≤ 2‖A⁻¹k‖ ≤ 2‖A⁻¹‖·‖k‖ = λ⁻¹‖k‖。
  4. f'(x) 可逆：x∈U，所以 ‖f'(x) − A‖·‖A⁻¹‖ < λ‖A⁻¹‖ = ½ < 1，由扰动引理成立。记 T = f'(x)⁻¹。
  5. 代数恒等式：g(y + k) − g(y) − Tk = h − Tk = −T[f(x + h) − f(x) − f'(x)h]。（验证：T·f'(x)h = h，且 f(x + h) − f(x) = k。）
  6. 估计：‖g(y + k) − g(y) − Tk‖/‖k‖ ≤ ‖T‖·‖f(x + h) − f(x) − f'(x)h‖/‖k‖ ≤ (‖T‖/λ)·‖f(x + h) − f(x) − f'(x)h‖/‖h‖，最后一步用了 1/‖k‖ ≤ λ⁻¹/‖h‖。
  7. k→0 ⇒ h→0（第 3 步）。由 f 在 x 处可微，右侧 → 0。所以 g 在 y 处可微，g'(y) = T = [f'(g(y))]⁻¹。
  8. C¹：g 可微因而连续；f' 是 U → Ω 的连续映射；求逆在 Ω 上连续。所以 g' = inv ∘ f' ∘ g 是连续映射的复合，g∈C¹。
  9. C^k（光滑）：求逆映射是光滑的。若 f∈C^k 且已知 g∈C^j（j<k），则 g' = inv∘f'∘g ∈ C^{min(j, k−1)}，即 g∈C^{j+1}。从 j=1 归纳到 j=k。
- necessity：
  - 第 3 步的控制 ‖h‖ ≤ λ⁻¹‖k‖ 是关键。对照 x³：其逆 y^{1/3} 在 0 附近 h = k^{1/3}，h/k → ∞，没有这样的控制，于是不可微。正是 A 的可逆性（通过 λ）给出了这个常数。
  - 第 4 步说明：f'(x) 在整个 U 上都可逆，这也是"一点可逆、靠连续性扩散到邻域"的体现，同样依赖 C¹（c04 例子 4）。
- visual_events：
  - e1｜回顾橙色标记｜c03 台账中的"导数公式需要 g 可微"重新出现，橙色闪烁｜无｜依赖链路标｜台账：f: U → V 双射，V 开，φ_y 是 ½-压缩
  - e2｜增量 h 与 k｜双面板：左 x 与 x + h，右 y 与 y + k，映射弧线 f 与 g｜k 缩短时 h 同步缩短｜e1 标记缩入台账｜标签 h = g(y + k) − g(y)
  - e3｜第 2–3 步：‖h‖ ≤ λ⁻¹‖k‖｜KaTeX：φ(x+h) − φ(x) = h − A⁻¹k，然后范数不等式链；左面板 h 周围画半径为 λ⁻¹‖k‖ 的圆，h 的终点始终在圆内｜k 缩小三次，圆与 h 一起缩小｜双面板保留｜台账加 ①‖h‖ ≤ λ⁻¹‖k‖
  - e4｜对照 x³｜右下小插图：y = x^{1/3} 在 0 附近，k 很小时 h 很大，比值 h/k 数字递增｜插图出现后淡出｜e3 保留｜标签"无此控制 ⇒ 不可微"
  - e5｜第 4–5 步：T 与代数恒等式｜KaTeX 逐项展开 h − Tk = −T[f(x + h) − f(x) − f'(x)h]，两侧对应项用颜色连线｜双面板缩小｜台账加 ②f'(x) 可逆（扰动引理），T = f'(x)⁻¹
  - e6｜第 6–7 步：误差比趋于 0｜曲线图：横轴 ‖k‖，纵轴 ‖g(y + k) − g(y) − Tk‖/‖k‖，用二维例子数值计算 30 个点，曲线趋于 0｜曲线绘出｜台账压缩：①②合并｜g'(y) = [f'(g(y))]⁻¹ 框出；c03 的橙色标记被划掉
  - e7｜第 8–9 步：C¹ 与 C^k｜复合链图：y →g→ x →f'→ f'(x)∈Ω →inv→ T，三个箭头都标"连续/光滑"｜依次点亮｜清空曲线｜定理框出现完整的"✓"
- outcome_check：观众能说明为什么 k→0 蕴含 h→0，以及为什么 x³ 的逆缺少这个性质；能写出 g' = inv ∘ f' ∘ g 并据此说明 g∈C¹。
- source：RU 9.24 证明 (b) 及其后的 C¹ 论证、9.8（可逆矩阵集合与求逆的连续性）；C^k 归纳属补充（L3 §2.1 陈述了 C^k 结论）
- next：定理证完了。最后看看它给了我们什么，又缺什么。

### c10-what-ift-buys — 它买到了什么，还缺什么

- question：反函数定理在全系列中提供了什么能力？为什么它还不足以处理约束集合？
- requires：ift-statement（e03-c03）、ift-proof（e03-c07 – c09）、chart-problem（e02-smooth-manifolds）
- music：recap
- teaching_sequence：
  - 直觉：反函数定理把"检查一个矩阵是否可逆"这种有限的线性代数计算，换成"附近存在光滑坐标变换"这种无穷维的几何结论。
  - 回顾证明结构：C¹ + 一点可逆 → 邻域内导数接近 A → φ_y 是 ½-压缩 → 单射；闭球 + 完备性 → 存在解 → V 开；增量控制 → 逆可微 → C¹/C^k。每个条件都在证明中找到了它的用处，也对应了 c04、c06 中的一个反例。
  - 例子：极坐标再出现。DF 可逆 ⇒ 局部可以用 (r,θ) 当坐标，这正是 chart 的雏形。
  - 边界：定理要求 F: ℝⁿ → ℝⁿ，即 n 个方程、n 个未知数。约束集合 {x∈ℝⁿ : h(x) = c}，h: ℝⁿ → ℝᵏ，k < n，方程比未知数少，Dh 不是方阵，无从谈"可逆"。例：圆 x² + y² = 1 只有一个方程、两个未知数。
  - 用途：E04 用一个技巧，把 F(x,y) = (x, f(x,y)) 补成方阵映射，再套用反函数定理，从而推出隐函数定理。
- proof_steps：无
- necessity：通过圆的例子说明 IFT 不能直接作用于约束集合：h(x,y) = x² + y² − 1 的 Dh = [2x, 2y] 是 1×2 矩阵。
- visual_events：
  - e1｜证明地图｜三列流程图：(a) 单射：C¹ → 球 U → ½-压缩 → 单射；(a) 开：闭球 → 完备 → 不动点 → V 开；(b) 可微：增量控制 → 恒等式 → g' = (f')⁻¹ → C^k｜每个节点旁挂一个反例缩略图（x+2x² sin(1/x)、x/2 on (0,1]、x³）｜节点逐一点亮｜依赖链路标｜流程图完整
  - e2｜极坐标 = chart 的雏形｜c04 e3 的长条与圆环，选一个小方块，现在标"局部坐标 (r,θ)"｜方块与其像来回映射｜流程图缩小｜标签"导数可逆 ⇒ 局部坐标"
  - e3｜缺什么：方程比未知数少｜平面上的单位圆，以及 Dh = [2x, 2y] 的 1×2 矩阵；矩阵旁标"不是方阵，不能求逆"｜圆上一点闪烁｜清空 e2｜问号
  - e4｜E04 预告｜依赖链路标中 IFT 节点变为已完成（实心），下一节点"隐函数定理"闪烁；圆上一点附近出现一小段被拉直成图像 y = g(x) 的示意｜依次｜清空｜结尾画面
- outcome_check：观众能说出反函数定理的三个条件各自在证明的哪一步被使用，并说明它为何不能直接应用于 h: ℝⁿ → ℝᵏ（k < n）。
- source：L3 §2–§3 过渡段（"The inverse function theorem concerns n equations in n unknowns"）；HW p9
