## 章节

### c01-why-curved — 为什么弯曲空间上的优化需要新语言

- question：观众能说出两个具体困难：(1) 欧氏梯度步会离开约束集；(2) 球面没有一套处处好用的全局坐标；并理解由此需要一种不依赖坐标的"附近"概念。
- requires：euclid-norm（受众已知）。
- music：motivation
- teaching_sequence：
  - 直觉：在球面 S² ⊂ ℝ³ 上找函数 f 的最小点，例如 f(x) = xᵀAx（其在单位球面上的最小值点是 A 的最小特征值对应的特征向量，补充例子）。像平地上那样沿 −∇f 走一步。
  - 定义：约束优化问题 min f(x) s.t. x ∈ M，M = S^{n−1} = {x ∈ ℝⁿ : ‖x‖ = 1}；欧氏梯度步 x⁺ = x − α∇f(x)。
  - 例子 1（离开球面）：‖x − αg‖² = ‖x‖² − 2α xᵀg + α²‖g‖² = 1 − 2α xᵀg + α²‖g‖²。即使 g ⊥ x（xᵀg = 0），仍有 ‖x⁺‖² = 1 + α²‖g‖² > 1（g ≠ 0 时），步长越大离得越远。
  - 例子 2（坐标退化）：经纬度 (θ, λ) ↦ (cos θ cos λ, cos θ sin λ, sin θ)。在北极 θ = π/2 处，所有 λ 都给出同一点，经度没有定义；北极附近两点在球面上相距很近，经度却可以相差 π。在 (θ, λ) 坐标里做梯度下降，极点附近的步长会被严重扭曲。SO(3) 的欧拉角有同样的退化（万向节锁），这里只作类比，不展开。
  - 边界：由于球面的整体形状，单一一套连续可逆的坐标不可能覆盖整个 S²（事实，本系列不证明）；但每一点附近都可以找到好的坐标。
  - 用途：引出纲领——"局部像 ℝⁿ，局部之间要拼接得好"。要说"局部"，先要能说"附近"；而在没有坐标的空间里，"附近"本身也需要重新定义。这正是本集要做的事。
- proof_steps：
  1. 计算 ‖x − αg‖² = (x − αg)ᵀ(x − αg) = xᵀx − 2α xᵀg + α² gᵀg。
  2. 代入 xᵀx = 1。若 xᵀg = 0 且 g ≠ 0，则 ‖x⁺‖² = 1 + α²‖g‖² > 1，所以 x⁺ ∉ S^{n−1}。
  3. 若 xᵀg ≠ 0，‖x⁺‖² = 1 当且仅当 α = 2xᵀg/‖g‖²，只有这一个特殊步长，一般步长都离开球面。
- necessity：如果只用全局坐标（经纬度），极点处坐标映射不可逆，"附近"在坐标里被扭曲。这说明"附近"不能依赖某一套坐标来定义，必须是空间本身的属性。
- visual_events：
  - e1｜旁白介绍"在球面上找最小值"｜3D 半透明单位球 S²，球面上用颜色表示 f(x) = xᵀAx 的热力图，A = diag(1, 2, 3)，标出最小点 ±e₁｜球缓慢转动到正视角后停止｜—｜球静止，最小点高亮
  - e2｜旁白"像平地上那样沿负梯度走一步"｜球面上一点 x（黄色），从 x 出发的箭头 −α∇f(x)（∇f 为 ℝ³ 中的欧氏梯度）｜箭头伸出，端点 x⁺ 出现在球外，从原点到 x⁺ 画虚线并标注 ‖x⁺‖ > 1｜球与热力图｜x⁺ 悬在球外，标签 "x⁺ ∉ S²"
  - e3｜旁白计算 ‖x − αg‖²｜右侧 KaTeX 公式块逐行出现 proof_steps 1–2｜公式依次出现，"+α²‖g‖²" 一项高亮｜球与 x⁺ 留在左侧｜公式块完整

### c02-metric-and-balls — 距离、开球与开集

- question：观众能用三角不等式证明开球是开集，并理解"不同的距离可以给出完全相同的开集"，从而意识到真正重要的是开集，而不是具体的距离数值。
- requires：metric 的直观、euclid-norm（受众已知）。
- music：definition
- teaching_sequence：
  - 直觉："附近"最朴素的意思是"距离小于 r"。
  - 定义：度量 d: X × X → [0, ∞) 满足 (i) d(x, y) = 0 ⇔ x = y；(ii) d(x, y) = d(y, x)；(iii) d(x, z) ≤ d(x, y) + d(y, z)。开球 B_r(x) = {y ∈ X : d(x, y) < r}。U ⊆ X 称为开集，若对每个 x ∈ U 存在 r > 0 使 B_r(x) ⊆ U。
  - 例子：ℝ² 上的欧氏距离 d₂ 与最大值距离 d_∞(x, y) = max_i |x_i − y_i|，前者的开球是圆盘，后者是正方形。
  - 边界：闭圆盘 {‖y‖ ≤ 1} 不是开集，因为边界点的任何开球都会伸出圆盘。
  - 用途：开集是"可以在每一点周围留出余地"的集合，这正是"局部"讨论需要的。
- proof_steps：
  - 命题 A（开球是开集）：
    1. 取 y ∈ B_r(x)，令 s = r − d(x, y) > 0。
    2. 对任意 z ∈ B_s(y)，由三角不等式 d(x, z) ≤ d(x, y) + d(y, z) < d(x, y) + s = r。
    3. 所以 B_s(y) ⊆ B_r(x)。y 是任取的，故 B_r(x) 是开集。
  - 命题 B（d₂ 与 d_∞ 给出相同的开集）：
    1. 对 v ∈ ℝⁿ，有 max_i |v_i| ≤ ‖v‖₂ ≤ √n · max_i |v_i|。
    2. 因此 B^{∞}_{r/√n}(x) ⊆ B^{2}_r(x) ⊆ B^{∞}_r(x)。
    3. 若 U 在 d₂ 下开：对 x ∈ U 有 B²_r(x) ⊆ U，于是 B^∞_{r/√n}(x) ⊆ U，U 在 d_∞ 下开。
    4. 若 U 在 d_∞ 下开：对 x ∈ U 有 B^∞_r(x) ⊆ U，于是 B²_r(x) ⊆ B^∞_r(x) ⊆ U，U 在 d₂ 下开。
    5. 两种距离的开集族完全相同。
- necessity：
  - 三角不等式不可省：命题 A 的第 2 步正是三角不等式；没有它，开球本身就可能不是开集，"开球"这个名字也就失去了意义。
  - 距离数值并不本质：命题 B 中两种距离数值不同、开球形状不同，但开集族相同，"附近"的含义完全一样。由此提出问题：能否直接把开集作为基本对象，而不经过距离？
- visual_events：
  - e1｜旁白"附近就是距离小于 r"｜2D 平面，中心点 x，半径 r 的圆盘（填充半透明），圆周画虚线表示不包含边界｜圆盘从半径 0 长到 r｜—｜开球 B_r(x)
  - e2｜旁白介绍开球中任取一点 y｜圆盘内点 y，线段 x–y 标 d(x,y)，剩余部分标 s = r − d(x,y)｜线段与标注出现｜开球｜两段长度标注
  - e3｜旁白"围绕 y 的小球完全落在大球里"｜以 y 为中心、半径 s 的小圆盘；小圆盘内一点 z，折线 x→y→z 与直线 x→z｜z 在小圆盘内绕圈移动（确定性参数 t），折线长度与 r 的比较实时显示 "d(x,z) ≤ d(x,y)+d(y,z) < r"｜大球、y、标注｜小球内切于大球
  - e4｜旁白"边界点做不到"｜同一平面，闭圆盘（实线边界），边界上点 b，以 b 为中心的小球半径从 0.5 缩到 0.05｜每一个小球都有一部分（红色）伸出闭圆盘｜—｜标注 "closed disk is not open"
  - e5｜旁白介绍 d_∞｜在同一中心叠加正方形开球 B^∞_r(x)（橙色）与圆盘 B²_r(x)（蓝色）、更小的正方形 B^∞_{r/√2}(x)（橙色虚线）｜三者依次出现，形成"方中有圆、圆中有方"的嵌套｜—｜嵌套图与公式 B^∞_{r/√n} ⊆ B²_r ⊆ B^∞_r
  - e6｜旁白"同一个开集，两种眼光"｜不规则开集 U（光滑 blob），其中三个采样点各自画出蓝圆与橙方，都落在 U 内｜采样点依次亮起｜嵌套图缩到角落｜文字 "same open sets ⇒ same notion of nearness"
- outcome_check：观众能独立写出"开球是开集"的三行证明，并能解释为什么 d₂ 与 d_∞ 下的开集相同。
- source：L2 §1.1（metric topology、open ball）；L3 §1.1（Euclidean topology）；HW p1（metric continuity 的写法）；命题 B 为补充。

### c03-topology-axioms — 拓扑：只保留开集

- question：观众能复述拓扑的三条公理，证明度量空间的开集满足它们，并用 ∩(−1/n, 1/n) = {0} 解释为什么交集只要求有限个。
- requires：metric-open-set（e01-c02）。
- music：definition
- teaching_sequence：
  - 直觉：把上一章中开集满足的性质抽出来，作为定义本身。
  - 定义：集合 X 上的拓扑是子集族 τ ⊆ 2^X，满足 (i) ∅, X ∈ τ；(ii) τ 中任意多个元素的并属于 τ；(iii) τ 中有限多个元素的交属于 τ。τ 的元素称为开集，(X, τ) 称为拓扑空间。
  - 例子：(a) 度量拓扑（证明见下）；(b) 平凡拓扑 τ = {∅, X}：开集最少；(c) 离散拓扑 τ = 2^X：每个子集都开（也是离散度量 d(x,y)=1（x≠y）诱导的拓扑）；(d) 子空间拓扑：A ⊆ X，τ_A = {U ∩ A : U ∈ τ}；S¹ ⊂ ℝ²、S² ⊂ ℝ³ 都以此获得拓扑。
  - 边界：无穷交可能不开。
  - 用途：后面所有关于"局部"的说法（收敛、连续、同胚、chart）都只用开集表述。
- proof_steps：
  - 命题 A（度量开集满足三条公理）：
    1. ∅：没有点需要检查，空真成立；X：对任意 x，任意 B_r(x) ⊆ X。
    2. 并：设 x ∈ ⋃_α U_α，则 x ∈ U_β 对某个 β，存在 r > 0 使 B_r(x) ⊆ U_β ⊆ ⋃_α U_α。
    3. 有限交：设 x ∈ U₁ ∩ ⋯ ∩ U_m，对每个 i 有 r_i > 0 使 B_{r_i}(x) ⊆ U_i。取 r = min{r₁, …, r_m} > 0（有限个正数的最小值为正），则 B_r(x) ⊆ U_i 对所有 i 成立，即 B_r(x) ⊆ ⋂_i U_i。
  - 命题 B（无穷交可以不开）：
    1. U_n = (−1/n, 1/n) ⊆ ℝ 都是开集。
    2. ⋂_{n≥1} U_n = {0}：0 属于每个 U_n；若 x ≠ 0，取 n > 1/|x|，则 x ∉ U_n。
    3. {0} 不开：任何 B_r(0) = (−r, r) 都含有非零点。
    4. 失效位置：命题 A 第 3 步中的 min 变成 inf_n (1/n) = 0，不再给出正半径。
  - 命题 C（子空间拓扑满足公理）：
    1. ∅ = ∅ ∩ A，A = X ∩ A。
    2. ⋃_α (U_α ∩ A) = (⋃_α U_α) ∩ A。
    3. ⋂_{i=1}^m (U_i ∩ A) = (⋂_i U_i) ∩ A。
- necessity：
  - 若公理 (iii) 允许无穷交，则度量拓扑本身都不满足公理（命题 B）。所以 (iii) 中的"有限"不是随意的限制，而是让 ℝⁿ 的常规开集成为一个拓扑的必要条件。
  - 平凡拓扑与离散拓扑说明：同一集合可以有极粗或极细的拓扑；拓扑决定哪些点算"附近"，下一章将看到它直接决定哪些数列收敛。
- visual_events：
  - e1｜旁白"把开集的性质抽出来"｜三张卡片依次出现：∅, X ∈ τ / ⋃ / ⋂ (finite)｜卡片滑入｜—｜三条公理并列
  - e2｜旁白证明"并"｜2D 平面上三个重叠的开 blob U₁, U₂, U₃，其并集外轮廓高亮；一点 x 在 U₂ 中，画 x 的小球｜小球在 U₂ 内，随后整个并集轮廓发光｜公理卡片缩到顶部｜并集与 x 的小球
  - e3｜旁白证明"有限交"｜两个开集 U₁, U₂ 的交（重叠区），x 在交内，两个半径 r₁、r₂ 的圆，取较小者 r｜较大的圆淡出，较小的圆留在交内｜—｜标注 r = min(r₁, r₂)
  - e4｜旁白"无穷多个呢？"｜数轴 [−1.2, 1.2]，开区间 (−1/n, 1/n) 以叠层彩条显示，n = 1 到 40 依次出现（每条比上一条更窄），左上角计数 n｜区间不断收缩，最终只剩 0 处一个点；右侧显示 r_n = 1/n 的数值递减到 0.025｜数轴｜点 {0}，以及 "inf 1/n = 0" 标注
  - e5｜旁白"{0} 不是开集"｜以 0 为中心的小区间 (−r, r)，r 从 0.3 缩到 0.01，每个区间内都标出非零点（红色）｜区间缩小，红点始终存在｜{0}｜标注 "{0} ∉ τ"
  - e6｜旁白介绍平凡与离散拓扑｜一个含 4 个点 {a, b, c, d} 的有限集合；左栏平凡拓扑：只画 ∅ 和全集两个圈；右栏离散拓扑：画出若干子集的圈（采样 6 个，标注 "sample of 2^X, 16 sets in total"）｜两栏并排出现｜—｜对比标题 "coarsest vs finest"
  - e7｜旁白介绍子空间拓扑｜ℝ² 中一个开圆盘 U 与单位圆 S¹ 相交；交集 U ∩ S¹ 是 S¹ 上的一段开弧（高亮）｜U 平移，开弧随之移动｜—｜标注 "open in S¹ = U ∩ S¹"
- outcome_check：观众能解释为什么三条公理中是"任意并"但只有"有限交"，并能给出 ∩(−1/n, 1/n) = {0} 这个反例及其失效的具体步骤（min 变 inf）。
- source：L2 §1（Definition 1、Examples 1–2）、§1.1；L3 §1.1；HW p3（定义拓扑空间、邻域）。子空间拓扑为补充，后续 S¹、S² 的例子需要它。

### c04-convergence — 收敛：开集决定哪些数列收敛

- question：观众能证明拓扑收敛与度量空间中的 ε–N 收敛等价，并能解释在平凡拓扑中一个数列为什么会同时收敛到每一点——从而理解为什么后面要加 Hausdorff 条件。
- requires：topology（e01-c03）、eps-delta（受众已知）。
- music：proof
- teaching_sequence：
  - 直觉："x_k 最终待在 x 的任意邻域里"。
  - 定义：x_k → x 当且仅当对每个含 x 的开集 U，存在 K，使 k ≥ K 时 x_k ∈ U。
  - 例子：在 ℝ 上 x_k = 1/k → 0。
  - 边界：平凡拓扑中极限不唯一；离散拓扑中只有最终常值的数列收敛。
  - 用途：优化算法产生迭代序列 x_k，我们关心它是否收敛、收敛到哪里——这需要极限唯一。
- proof_steps：
  - 命题 A（度量空间中两种收敛等价）：
    1. (拓扑 ⇒ ε–N)：给定 ε > 0，B_ε(x) 是含 x 的开集（e01-c02 命题 A），所以存在 K，使 k ≥ K 时 x_k ∈ B_ε(x)，即 d(x_k, x) < ε。
    2. (ε–N ⇒ 拓扑)：设 U 开且 x ∈ U，存在 ε > 0 使 B_ε(x) ⊆ U。由 ε–N，存在 K，使 k ≥ K 时 d(x_k, x) < ε，于是 x_k ∈ B_ε(x) ⊆ U。
  - 命题 B（度量空间中极限唯一）：
    1. 设 x_k → x 且 x_k → y，x ≠ y。令 r = d(x, y)/2 > 0。
    2. B_r(x) ∩ B_r(y) = ∅：若 z 同属两者，则 d(x, y) ≤ d(x, z) + d(z, y) < 2r = d(x, y)，矛盾。
    3. 存在 K₁、K₂，使 k ≥ K₁ 时 x_k ∈ B_r(x)，k ≥ K₂ 时 x_k ∈ B_r(y)。取 k ≥ max(K₁, K₂)，x_k 同属两个不相交的集合，矛盾。
  - 命题 C（平凡拓扑中数列收敛到每一点）：
    1. 设 X 至少有两点，τ = {∅, X}。任取数列 (x_k) 与任意点 x。
    2. 含 x 的开集只有 X；所有 x_k ∈ X，取 K = 1 即可。
    3. 所以 x_k → x 对每个 x ∈ X 成立。
  - 命题 D（离散拓扑中 x_k → x ⇔ 数列最终等于 x）：
    1. {x} 是开集，所以存在 K 使 k ≥ K 时 x_k ∈ {x}。
    2. 反之，若最终 x_k = x，则对任意含 x 的开集，最终都有 x_k ∈ U。
- necessity：
  - 命题 B 的证明关键在第 2 步：两点可以被不相交的开集分开。平凡拓扑没有这种开集，极限就不唯一（命题 C）。对优化而言，"迭代收敛到最优点"如果极限不唯一就毫无意义。E02 会把"任意两点可被不相交开集分开"作为流形定义中的 Hausdorff 条件。
  - 命题 C、D 合起来说明：同一个数列，在不同拓扑下可以"收敛到所有点"或"根本不收敛"。收敛不是数列自身的属性，而是由开集决定的。
- visual_events：
  - e1｜旁白给出定义｜数轴上点 x = 0，数列 x_k = (−1)^k / k 的点（k = 1…30）依次落下，颜色由冷到暖；一个含 0 的开区间 U（半透明条）｜点逐个出现；U 内的点变亮；标出 K｜—｜U 外只剩有限个点
  - e2｜旁白"无论 U 多小"｜U 收缩三次（宽 0.5 → 0.2 → 0.05），每次 K 标签重新计算并右移｜K 数字变化：3 → 6 → 21｜数列点｜最窄的 U 与 K = 21
  - e3｜旁白证明命题 A｜右侧 KaTeX 两栏："topological ⇒ ε–N" 与 "ε–N ⇒ topological"，分别对应左侧画面中 U = B_ε(x) 与 B_ε(x) ⊆ U 两张小图｜两栏逐行出现，左侧小图同步高亮对应集合｜—｜两栏证明完整
  - e4｜旁白证明极限唯一｜平面上两点 x、y，半径 d(x,y)/2 的两个开球（不相交，中间留缝）；数列点落入 x 的球｜有一个"假设"标签 "suppose x_k → y too"，数列点被迫同时出现在两个球中，出现红色叉号｜—｜标注 "disjoint neighborhoods ⇒ unique limit"
  - e5｜旁白"现在换成平凡拓扑"｜同一平面背景变为单一大框 X（唯一的非空开集），框内三点 x, y, z 与数列点｜分别以 x、y、z 为"候选极限"，每次唯一可用的邻域都是整个 X，数列点全部在内，三个候选都打勾｜—｜三个绿色对勾，标注 "converges to every point"
  - e6｜旁白"离散拓扑下几乎不收敛"｜同一数列，在每个点周围画单点开集 {x}，数列 1/k 永远不落入 {0}｜数列点在 0 附近徘徊但不等于 0，红叉｜—｜标注 "only eventually-constant sequences converge"
  - e7｜旁白预告 Hausdorff｜文字卡 "Hausdorff: distinct points have disjoint open neighborhoods → E02"｜卡片出现｜—｜卡片停留
- outcome_check：观众能用两行证明说明拓扑收敛与 ε–N 收敛等价，并能解释"平凡拓扑中极限不唯一"的原因（没有不相交的邻域）。
- source：L2 §2（Definition 2 及与度量定义一致的说明）；HW p1（Topological x = lim x_i）；BD（板书 589d：Topological convergence）。命题 B–D 为补充；Hausdorff 在 L2 §5、L3 §1.2 中作为流形条件出现。

### c05-continuity — 连续：开集的原像是开集

- question：观众能完整证明"原像定义的连续"与"ε–δ 连续"在度量空间中等价，并证明连续映射保持收敛、连续映射的复合仍连续。
- requires：topology（e01-c03）、convergence（e01-c04）、eps-delta（受众已知）。
- music：proof
- teaching_sequence：
  - 直觉：ε–δ 说"输出想要多接近，输入只需足够接近"；换成开集：任何目标邻域 V，都有一整块输入邻域被送进 V。
  - 定义：f: X → Y 连续，若对每个开集 V ⊆ Y，f⁻¹(V) = {x ∈ X : f(x) ∈ V} 是 X 中的开集。
  - 例子：f(x) = x² 在 ℝ 上；V = (1, 4) 时 f⁻¹(V) = (−2, −1) ∪ (1, 2)，是开集。
  - 边界：连续性依赖于两边的拓扑：同一个恒等映射 id: (ℝ, 离散) → (ℝ, 标准) 连续，反方向 id: (ℝ, 标准) → (ℝ, 离散) 不连续（{0} 在离散拓扑中开，但它在标准拓扑中的原像 {0} 不开）。
  - 用途：chart、转移映射、光滑映射（E02）的定义都建立在连续之上；连续保持收敛，意味着在 chart 坐标里看到的收敛与流形上的收敛一致。
- proof_steps：
  - 命题 A（度量空间中：原像连续 ⇔ 每点 ε–δ 连续）：
    1. (⇒) 固定 x ∈ X 与 ε > 0。V = B_ε(f(x)) 在 Y 中开，所以 f⁻¹(V) 在 X 中开，且 x ∈ f⁻¹(V)。
    2. 由开集定义，存在 δ > 0 使 B_δ(x) ⊆ f⁻¹(V)，即 d_X(x, x') < δ ⇒ f(x') ∈ B_ε(f(x)) ⇒ d_Y(f(x), f(x')) < ε。
    3. (⇐) 设 V ⊆ Y 开，取 x ∈ f⁻¹(V)。因为 f(x) ∈ V 且 V 开，存在 ε > 0 使 B_ε(f(x)) ⊆ V。
    4. 由 ε–δ 连续，存在 δ > 0 使 f(B_δ(x)) ⊆ B_ε(f(x)) ⊆ V，所以 B_δ(x) ⊆ f⁻¹(V)。
    5. x 是 f⁻¹(V) 中任意一点，故 f⁻¹(V) 开。
  - 命题 B（连续映射保持收敛）：
    1. 设 f 连续，x_k → x。取任意含 f(x) 的开集 V。
    2. f⁻¹(V) 开且含 x，所以存在 K，使 k ≥ K 时 x_k ∈ f⁻¹(V)，即 f(x_k) ∈ V。
    3. 所以 f(x_k) → f(x)。
  - 命题 C（复合保持连续）：
    1. 设 f: X → Y、g: Y → Z 连续，W ⊆ Z 开。
    2. (g ∘ f)⁻¹(W) = f⁻¹(g⁻¹(W))。g⁻¹(W) 在 Y 中开，再取 f 的原像，在 X 中开。
- necessity：
  - 命题 A 说明原像定义没有丢失任何 ε–δ 的信息，但它不再需要距离——因此可以用在没有自然距离的空间上（例如抽象流形）。
  - 恒等映射的例子说明：连续性不是公式本身的性质，而是"公式 + 两边的开集"的性质。把拓扑换掉，连续性就可能改变。
  - 命题 B 是下一章"连续逆"必要性证明中要用的工具。
- visual_events：
  - e1｜旁白回顾 ε–δ｜2D 图像：曲线 y = f(x)（取 f(x) = x²/2 + sin x），点 (x₀, f(x₀))；y 轴上 ε 带（水平半透明条），x 轴上 δ 带（竖直条）｜先出现 ε 带，再出现 δ 带，δ 带内的曲线段落入 ε 带并变绿｜—｜经典 ε–δ 图
  - e2｜旁白"换成开集的语言"｜双面板：左 X、右 Y（blob 形状），f 用弯箭头连接；Y 中开集 V，X 中原像 f⁻¹(V)（可由两块组成）｜V 出现后，其原像区域在 X 中高亮｜—｜双面板与标注 "f⁻¹(V) open"
  - e3｜旁白证明 (⇒)｜ε–δ 图上 ε 带被重新标为 V = B_ε(f(x₀))；x 轴上它的原像（可能多段）高亮，x₀ 周围取出一个 δ 区间落在原像内｜原像高亮 → δ 区间出现｜ε–δ 图｜右侧公式 proof_steps 1–2
  - e4｜旁白证明 (⇐)｜双面板中 V 内一点 f(x)，ε 球在 V 内；X 中 δ 球被 f 送进 ε 球｜δ 球的像以变形动画移动到 Y 并落入 ε 球｜双面板｜右侧公式 proof_steps 3–5
  - e5｜旁白证明保持收敛｜X 中数列点逼近 x，Y 中对应 f(x_k) 逼近 f(x)；Y 中开集 V 及其原像｜数列逐点映射，最终都进入 V｜—｜标注 "x_k → x ⇒ f(x_k) → f(x)"
  - e6｜旁白复合｜三个面板 X → Y → Z，W ⊆ Z，原像依次向左传递 g⁻¹(W)、f⁻¹(g⁻¹(W))｜区域依次高亮向左传播｜—｜公式 (g∘f)⁻¹(W) = f⁻¹(g⁻¹(W))
  - e7｜旁白"连续性取决于拓扑"｜两行：id: (ℝ, discrete) → (ℝ, standard) ✓；id: (ℝ, standard) → (ℝ, discrete) ✗，后者旁画 {0} 及其原像 {0}，标"open on the right, not open on the left"｜两行依次出现｜—｜对比卡
- outcome_check：观众能写出命题 A 两个方向的证明，并能说出恒等映射在什么拓扑下不连续。
- source：L2 §3（Definition 3 及与 ε–δ 一致的说明）；L3 §1.1；HW p1（continuous 定义、Metric continuity）；BD（板书 589d：Metric continuity）。命题 B、C 及恒等映射例子为补充。

### c06-preimage-not-image — 为什么是原像，而不是像

- question：观众能给出两个反例，说明"开集的像是开集"既不是连续的必要条件，也不能刻画连续；并说出原像定义抓住的是"输入变化小，输出变化小"这个方向。
- requires：continuity（e01-c05）。
- music：counterexample
- teaching_sequence：
  - 直觉：连续关心的是"输出要落在目标邻域里，输入允许在哪里"——这是从输出往回看，所以是原像。
  - 定义：开映射：把开集映为开集的映射（只用于对比）。
  - 例子：(a) 常值映射 c: ℝ → ℝ, c(x) = 0；(b) f(x) = x²；再加上"原像与集合运算交换"这一结构原因。
  - 边界：原像与并、交、补都交换，像不与交交换；这是原像定义能与拓扑公理配合的结构原因。
  - 用途：同胚恰好是"原像方向与像方向都保持开集"的映射，下一章由此定义。
- proof_steps：
  - 命题 A（常值映射连续，但不是开映射）：
    1. 对开集 V ⊆ ℝ，c⁻¹(V) = ℝ（若 0 ∈ V）或 ∅（若 0 ∉ V），两者都开，所以 c 连续。
    2. c(ℝ) = {0} 不是开集，所以 c 把开集映为非开集。
  - 命题 B（x² 连续，但把开集 (−1, 1) 映为 [0, 1)）：
    1. f(x) = x² 是多项式，ε–δ 连续，由 e01-c05 命题 A，原像意义下也连续。
    2. f((−1, 1)) = [0, 1)：对 x ∈ (−1, 1)，0 ≤ x² < 1；反之 y ∈ [0, 1) 时 y = (√y)²，√y ∈ [0, 1)。
    3. [0, 1) 不开：任何 (−r, r) 都含有负数，而负数不在 [0, 1) 中，所以 0 处没有开球留在集合里。
  - 命题 C（原像与集合运算交换，像不与交交换）：
    1. f⁻¹(⋃_α V_α) = ⋃_α f⁻¹(V_α)，f⁻¹(⋂_i V_i) = ⋂_i f⁻¹(V_i)：x 属于左边 ⇔ f(x) 属于相应的并/交 ⇔ x 属于右边。
    2. 反例：f(x) = x²，A = (−2, −1)，B = (1, 2)，A ∩ B = ∅，但 f(A) ∩ f(B) = (1, 4) ≠ f(A ∩ B) = ∅。
- necessity：
  - 若把"连续"定义为"开集的像是开集"，常值映射——最"连续"的映射——将不连续；x² 也不连续。这样的定义与直觉和 ε–δ 都不一致。
  - 原像方向与 ε–δ 的方向一致：先给定输出的允许范围 ε（目标开集 V），再问输入的允许范围 δ（原像）。
- visual_events：
  - e1｜旁白"如果用像来定义会怎样"｜双面板：左 ℝ 上开区间 (−1, 1)（蓝条），右 ℝ｜—｜—｜问题文字 "image of open = open?"
  - e2｜旁白常值映射｜(−1, 1) 中点阵（21 个采样点）全部飞向右侧 0 点｜点群汇聚成一点，右侧标出 {0}，旁注 "not open"｜左侧区间｜一个点 {0}
  - e3｜旁白"但它是连续的"｜右侧任意开区间 V（两种：含 0 和不含 0），左侧原像分别为整个 ℝ 和 ∅｜两种情况依次演示｜—｜两个结果都打勾 "open"
  - e4｜旁白 x² 的例子｜2D 坐标系，抛物线 y = x²，x 轴上的 (−1, 1)，竖直投影到 y 轴得到 [0, 1)｜投影光束从 x 轴区间射向曲线再水平射向 y 轴，y 轴上 0 处画实心点、1 处画空心点｜—｜标注 "f((−1,1)) = [0,1), not open"
  - e5｜旁白"0 附近的小区间伸出去了"｜y 轴 0 处的小区间 (−r, r)，负半部分涂红｜r 缩小，红色部分始终存在｜抛物线｜红色标注
  - e6｜旁白原像与交集交换、像不交换｜抛物线上 A = (−2, −1) 与 B = (1, 2)（x 轴上两段不相交的条），它们的像在 y 轴上重合为 (1, 4)｜两条像光束汇聚到同一段｜—｜公式 f(A) ∩ f(B) ≠ f(A ∩ B)
- outcome_check：观众能举出常值映射与 x² 两个例子，说明它们连续但不把开集映为开集。
- source：L2 §3（open-set 定义与 ε–δ 的方向一致）；BD（板书 a8aa：同胚需要 "bijective on open sets"）。反例为补充。
- next：只在一个方向上保持开集是连续；如果两个方向都保持开集，就得到"拓扑上相同"——同胚。

### c07-homeomorphism — 同胚：拓扑意义下的"相同"

- question：观众能说出同胚的三个条件，证明同胚在开集族之间建立双射，并用 (−1, 1) ≅ ℝ 说明长度、有界性都不是拓扑性质。
- requires：continuity（e01-c05）、preimage-not-image（e01-c06）。
- music：definition
- teaching_sequence：
  - 直觉：两个空间"一样"，意味着点一一对应，而且"附近"的结构也一一对应——一边的开集恰好对应另一边的开集。
  - 定义：f: X → Y 是同胚，若 (i) f 是双射；(ii) f 连续；(iii) f⁻¹ 连续。存在同胚时记 X ≅ Y。
  - 例子：(a) f: (−1, 1) → ℝ，f(x) = tan(πx/2)，逆 f⁻¹(y) = (2/π) arctan y；(b) ℝ² 中开圆盘与开正方形同胚（只作展示，不证明）。
  - 边界：同胚保持开集、收敛、连续性；不保持距离、长度、有界性。
  - 用途：chart 就是从流形的开集到 ℝⁿ 开子集的同胚（E02）；"局部像 ℝⁿ"的精确含义就是"局部同胚于 ℝⁿ 的开子集"。
- proof_steps：
  - 命题 A（同胚诱导开集族之间的双射 U ↦ f(U)）：
    1. 若 U ⊆ X 开，则 f(U) = (f⁻¹)⁻¹(U)（这里 (f⁻¹)⁻¹(U) 指 U 在映射 f⁻¹: Y → X 下的原像；因为 f 是双射，y ∈ f(U) ⇔ f⁻¹(y) ∈ U）。f⁻¹ 连续，所以 f(U) 在 Y 中开。
    2. 若 V ⊆ Y 开，则 f⁻¹(V) 在 X 中开（f 连续），且 f(f⁻¹(V)) = V（f 满射）。
    3. 所以 U ↦ f(U) 是 X 的开集族到 Y 的开集族的双射，逆为 V ↦ f⁻¹(V)。
  - 命题 B（f(x) = tan(πx/2) 是 (−1, 1) → ℝ 的同胚）：
    1. 双射：tan 在 (−π/2, π/2) 上严格递增，且当 x → ±1 时 f(x) → ±∞；由中值定理取遍 ℝ。
    2. f 连续（tan 在 (−π/2, π/2) 上连续）。
    3. f⁻¹(y) = (2/π) arctan y 连续。
  - 命题 C（同胚是等价关系）：
    1. 恒等映射是同胚；f 是同胚则 f⁻¹ 也是；同胚的复合是同胚（双射复合为双射，连续复合为连续，由 e01-c05 命题 C，(g ∘ f)⁻¹ = f⁻¹ ∘ g⁻¹ 连续）。
- necessity：
  - 板书的说法"bijective on points 且 bijective on open sets"就是命题 A；条件 (iii) 正是保证"开集到开集"这一方向（命题 A 第 1 步用到了 f⁻¹ 连续）。下一章证明：去掉 (iii)，即使 f 连续且双射，开集结构也会被破坏。
  - (−1, 1) ≅ ℝ 说明同胚完全不关心长度：有界区间与整条直线拓扑上相同。所以"局部像 ℝⁿ"等价于"局部像 ℝⁿ 中的一个开集"，这也是 chart 定义中目标取 ℝⁿ 开子集的原因。

### c08-continuous-inverse — 连续逆为什么不能省

- question：观众能完整证明 f: [0, 2π) → S¹，f(t) = (cos t, sin t) 是连续双射但不是同胚，并说出这对 chart 的含义：用 t 当 S¹ 的坐标，会在 (1, 0) 处撕开。
- requires：homeomorphism（e01-c07）、convergence（e01-c04）、continuity 命题 B（e01-c05）、子空间拓扑（e01-c03）。
- music：counterexample
- teaching_sequence：
  - 直觉：把一段线段 [0, 2π) 弯成圆，首尾"几乎"接上但没有粘合；从圆回到线段时，在接缝处必须撕开。
  - 定义：[0, 2π) 与 S¹ 都取子空间拓扑（分别来自 ℝ、ℝ²）。
  - 例子：t_k = 2π − 1/k 对应的点 p_k = f(t_k) 在圆上逼近 (1, 0)，而 t_k → 2π，不趋于 0 = f⁻¹(1, 0)。
  - 边界：如果把定义域换成开区间 (0, 2π)，f 就是到 S¹ \ {(1, 0)} 的同胚（这里只陈述，E02 用它构造 chart）。
  - 用途：chart 必须是同胚；因此单个"角度坐标"覆盖不了整个 S¹，S¹ 至少需要两个 chart——这是 E02 的起点。
- proof_steps：
  - 命题（f 连续、双射，但 f⁻¹ 不连续）：
    1. 连续：f 的两个分量 cos t、sin t 在 ℝ 上连续，限制在 [0, 2π) 上仍连续，取值在 S¹ 中。
    2. 单射：若 f(s) = f(t)，s, t ∈ [0, 2π)，则 cos s = cos t 且 sin s = sin t，所以 s − t ∈ 2πℤ；又 |s − t| < 2π，故 s = t。
    3. 满射：任一 (a, b) ∈ S¹ 有 a² + b² = 1，存在唯一 t ∈ [0, 2π) 使 (cos t, sin t) = (a, b)（极角）。
    4. f⁻¹ 不连续（用 e01-c05 命题 B 的逆否）：令 p_k = f(2π − 1/k)（k ≥ 1，2π − 1/k ∈ [0, 2π)）。
    5. p_k → (1, 0)：‖p_k − (1, 0)‖² = (cos(1/k) − 1)² + sin²(1/k) = 2 − 2cos(1/k) → 0。
    6. 但 f⁻¹(p_k) = 2π − 1/k → 2π，而 f⁻¹(1, 0) = 0；|f⁻¹(p_k) − 0| > π 对所有 k ≥ 1 成立，所以 f⁻¹(p_k) 不收敛到 f⁻¹(1, 0)。
    7. 若 f⁻¹ 连续，由 e01-c05 命题 B，应有 f⁻¹(p_k) → f⁻¹(1, 0)。矛盾，所以 f⁻¹ 不连续。
  - 开集角度的同一事实：
    8. [0, 1) = (−1, 1) ∩ [0, 2π) 在子空间拓扑中是 [0, 2π) 的开集。
    9. f([0, 1)) 是从 (1, 0) 起、逆时针到角度 1 的弧，包含 (1, 0)。任何含 (1, 0) 的 S¹ 开集都含有角度略小于 2π 的点（例如 p_k，k 足够大），而这些点不在弧中，所以 f([0, 1)) 在 S¹ 中不开。这正是命题 A（e01-c07）第 1 步失效之处。
- necessity：
  - 条件 (iii) 不可省：连续 + 双射不足以保证"拓扑相同"。[0, 2π) 和 S¹ 在拓扑上不同（[0, 2π) 去掉 t = π 后不连通，S¹ 去掉任一点后仍连通，这里作为直观对照，不证明）。
  - 对优化的含义：若把 t 当作 S¹ 的坐标，圆上紧挨着的两点 (1, 0) 与 p_k 的坐标是 0 与接近 2π 的数。坐标里的距离不再反映流形上的距离，在坐标里做梯度步会在接缝处跳跃。chart 要求同胚，正是为了排除这种撕裂。
- visual_events：
  - e1｜旁白"把线段弯成圆"｜2D：水平线段 [0, 2π)，左端实心点、右端空心点，线段上均匀色带（色相随 t 变化）｜线段弯曲成圆（插值 s：0 → 1），色带保持，左端落在 (1, 0)，右端空心点在 (1, 0) 处与左端重合但不粘合｜—｜彩色圆，(1, 0) 处标注 "t = 0" 和 "t → 2π"
  - e2｜旁白证明连续与双射｜右侧 KaTeX 公式块 proof_steps 1–3｜逐行出现｜圆｜公式块
  - e3｜旁白"圆上逼近 (1, 0) 的点"｜圆上点 p_k（k = 1…12）从下方顺时针逼近 (1, 0)，在圆上越来越密｜点依次出现｜圆、色带｜点群聚集在 (1, 0) 下方
  - e4｜旁白"把它们送回线段"｜下方再画一条线段 [0, 2π)，p_k 的原像 t_k = 2π − 1/k 在线段右端聚集；(1, 0) 的原像 t = 0 在左端｜每个 p_k 以弧线飞到线段右端；(1, 0) 飞到左端；左右两端之间画红色双箭头，标注 "distance → 2π"｜圆保持｜标注 "p_k → (1,0) but f⁻¹(p_k) ↛ 0"
  - e5｜旁白开集角度｜线段左端开集 [0, 1)（子空间意义下开，蓝条）与它在圆上的像（蓝弧，含 (1, 0)）；在 (1, 0) 周围画一个小圆盘，与 S¹ 的交是跨过 (1, 0) 的小弧，下半段（红色）不在蓝弧里｜小圆盘半径缩小，红段始终存在｜—｜标注 "open in [0,2π), not open in S¹"
  - e6｜旁白"把 t 当坐标会在接缝撕开"｜圆上紧邻 (1, 0) 两侧的两点 A（角度 0.05）、B（角度 2π − 0.05），它们在线段上的坐标相距约 6.18；一个梯度步的小箭头从 A 跨到 B，在线段上变成一大步跳跃｜箭头在圆上很短、在线段上很长｜—｜标注 "coordinates must preserve nearness both ways"

### c09-bridge-to-charts — 总结与通向 chart

- question：观众能复述本集的逻辑链，并能说出 chart 的定义中每个词（开集、同胚、ℝⁿ 的开子集）分别来自本集的哪一章。
- requires：本集全部内容。
- music：recap
- teaching_sequence：
  - 直觉：回到 c01 的球面，现在我们拥有描述"局部"的全部词汇。
  - 定义（预告，E02 正式展开）：拓扑空间 M 上的 chart 是 (U, φ)，U ⊆ M 开，φ: U → φ(U) ⊆ ℝⁿ 是到 ℝⁿ 开子集的同胚。拓扑流形：每一点都在某个 chart 的定义域中（另加 Hausdorff 与第二可数两个技术条件）。
  - 例子：S¹ 上半圆 U = {(x, y) ∈ S¹ : y > 0}，φ(x, y) = x，φ⁻¹(x) = (x, √(1 − x²))（HW p4）。
  - 边界：拓扑流形只能谈连续，不能谈导数；要做梯度下降，还需要光滑结构（E02）。
  - 用途：E02 用 chart 定义拓扑流形与光滑流形。
- proof_steps：
  - 命题（上半圆 chart 是同胚）：
    1. φ(x, y) = x 是 ℝ² → ℝ 坐标投影在 U 上的限制，连续。
    2. φ(U) = (−1, 1)：U 中点满足 x² < 1；反之 x ∈ (−1, 1) 时 (x, √(1 − x²)) ∈ U。
    3. ψ(x) = (x, √(1 − x²)) 在 (−1, 1) 上连续，φ ∘ ψ = id，ψ ∘ φ = id（因为 y > 0 时 y = √(1 − x²)），所以 φ 是双射且 φ⁻¹ = ψ 连续。
    4. U = S¹ ∩ {y > 0} 是 S¹ 的开集（子空间拓扑），(−1, 1) 是 ℝ 的开集。故 (U, φ) 是 chart。
- necessity：
  - 对比 c08：参数 t 想一次覆盖整个圆而失败；chart 只覆盖一个开集，因而可以是真正的同胚。代价是需要多个 chart，并且 chart 之间要相容——这是 E02 的核心问题。
- visual_events：
  - e1｜旁白回顾逻辑链｜竖向流程图：distance → open ball → open set → topology → convergence / continuity → homeomorphism，每个节点带本集章号｜节点依次点亮｜—｜流程图
  - e2｜旁白定义 chart｜回到 c01 的球面，在球面上取一片开集 U（高亮补丁），映射 φ 把它展平到 ℝ² 中的开集 φ(U)（下方平面上的 blob），映射箭头双向（φ 与 φ⁻¹）｜补丁从球上"剥离"并展平｜流程图缩到左侧｜补丁与平面开集
  - e3｜旁白给出公式定义｜KaTeX：(U, φ)，U ⊆ M open，φ: U → φ(U) ⊆ ℝⁿ homeomorphism；每个词连线到流程图对应节点｜连线依次出现｜—｜定义卡
  - e4｜旁白 S¹ 上半圆例子｜2D 单位圆，上半圆高亮，竖直投影到 x 轴上的 (−1, 1)，端点空心｜投影线扫过上半圆｜—｜φ(x, y) = x，φ⁻¹(x) = (x, √(1−x²))
  - e5｜旁白"但一个 chart 不够，而且 chart 之间要拼接"｜圆上再出现下半圆与左右半圆的 chart（四种颜色），重叠区域闪烁，出现问号 "how do overlaps agree? → E02"｜四个补丁依次出现｜上半圆 chart｜四色覆盖的圆与问题文字
- outcome_check：观众能指出 chart 定义中"同胚"一词为什么不能换成"连续双射"（引用 c08），以及"ℝⁿ 的开子集"为什么足够（引用 c07 的 (−1, 1) ≅ ℝ）。
- source：L2 §5（Definition 5–6）；L3 §1.2（Definition 3–4）；HW p2（Manifold informal/formal）、HW p4（S¹ chart φ₁）；BD（板书 960f：Manifolds informally/formally；589d：φ: U → V）。
