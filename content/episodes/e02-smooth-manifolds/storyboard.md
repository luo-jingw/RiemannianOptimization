# E02 — Charts, Atlases and Smooth Manifolds

## 全集框架

- 核心问题：一个空间可能整体弯曲、没有全局坐标，怎样才能在上面做微积分？进一步，"f 在 M 上光滑"这句话要满足什么条件才有唯一的意义？
- 受众起点：E01 已建立开集、收敛、连续（开集的原像为开集）和同胚。熟悉 ℝⁿ 上的多元微积分：偏导数、链式法则、光滑（C^∞）。见过课上的流形定义，但不理解每个条件的作用。
- 主线：局部用坐标描述（chart）→ 一个 chart 不够，需要多个 → 拓扑流形（Hausdorff 保证极限唯一）→ 重叠处同一点有两套坐标（转移映射）→ 坐标之间不相容会让"光滑"产生歧义 → 光滑图册与极大图册 → 光滑映射，证明定义与 chart 选择无关 → 微分同胚 → 内蕴与外蕴视角：手工构造 O(n) 的 chart 不可行，需要由方程生成 chart 的定理（E03/E04）。

### c01-recap-e01 — 上一集的工具箱

- question：观众能复述本集要用到的 E01 三件工具：开集、连续、同胚。
- requires：open-set、continuity、homeomorphism（e01）。
- music：recap
- teaching_sequence：
  - 直觉：拓扑只保留"谁靠近谁"的信息，不需要距离和坐标。
  - 定义（复述）：拓扑 τ 是一组开集，满足 ∅、X ∈ τ，对任意并封闭，对有限交封闭。f 连续 ⇔ 对任意开集 V，f⁻¹(V) 都是开集。同胚 = 双射 + 连续 + 逆连续。
  - 例子：[0, 2π) → S¹，t ↦ (cos t, sin t) 是连续双射，但逆映射在 (1, 0) 处把圆"撕开"，所以不是同胚（E01 的反例，此处只回放结论）。
  - 边界：同胚把一个空间的开集一一对应到另一个空间的开集，因此保持"靠近"关系；它不涉及光滑性。
  - 用途：本集的 chart 就是"到 ℝ^d 开子集的同胚"。
- proof_steps：无（复述）。
- necessity：无（复述）。

### c02-charts-on-the-circle — 坐标卡：圆的局部坐标

- question：观众能写出 S¹ 上半圆的 chart 及其逆，验证它是同胚，并解释为什么 S¹ 必须用不止一个 chart。
- requires：homeomorphism（e01）、compact-connected（受众已知）。
- music：definition
- teaching_sequence：
  - 直觉：在地球表面一小块区域里，地图可以做得毫无破绽；但一张平面地图盖不住整个地球。圆 S¹ 是这件事的一维版本。
  - 定义：设 M 是拓扑空间。d 维 chart 是一对 (U, φ)，其中 U ⊆ M 是开集，φ : U → φ(U) ⊆ ℝ^d 是到 ℝ^d 中某个开子集的同胚。φ(p) 称为 p 的局部坐标。
  - 例子：S¹ = {(x, y) ∈ ℝ² : x² + y² = 1}。U₊ = {(x, y) ∈ S¹ : y > 0}，φ₊(x, y) = x，φ₊(U₊) = (−1, 1)，逆映射 φ₊⁻¹(x) = (x, √(1 − x²))。
  - 例子（覆盖整圆）：四个半圆 chart。U₊ 与 U₋ = {y < 0} 都用坐标 x；U_r = {x > 0} 与 U_l = {x < 0} 都用坐标 y。四者覆盖 S¹：圆上任一点的 x、y 不会同时为 0。
  - 例子（另一种）：球极投影。N = (0, 1)，S = (0, −1)。σ_N(x, y) = x / (1 − y) 定义在 S¹∖{N} 上；σ_S(x, y) = x / (1 + y) 定义在 S¹∖{S} 上。两个 chart 覆盖 S¹。
  - 边界：一个 chart 盖不住 S¹（定理及证明见下）。chart 的像必须是开集：若取闭上半圆 {y ≥ 0}，φ₊ 仍是单射，但像为 [−1, 1]，不是开集，端点 (±1, 0) 会被误当成"边界点"，而圆其实没有边界。
  - 用途：chart 把 M 上的局部问题搬到 ℝ^d 的开集上，那里有现成的微积分。
- proof_steps：
  1. 命题 A：(U₊, φ₊) 是 chart。
     1. U₊ 是 S¹ 中的开集：U₊ = S¹ ∩ {(x, y) : y > 0}，是 ℝ² 中开半平面与 S¹ 的交，在子空间拓扑中是开集。
     2. φ₊ 是限制在 U₊ 上的坐标投影 (x, y) ↦ x，投影连续，限制后仍连续。
     3. 单射：若 φ₊(x₁, y₁) = φ₊(x₂, y₂)，则 x₁ = x₂；又 y₁ = √(1 − x₁²) = y₂（因为 y > 0 只能取正根），所以两点相同。
     4. 满射到 (−1, 1)：对任意 x ∈ (−1, 1)，点 (x, √(1 − x²)) 满足 x² + y² = 1 且 y > 0，所以它属于 U₊，且被映到 x。
     5. 逆映射 x ↦ (x, √(1 − x²)) 在 (−1, 1) 上连续，因为 √ 在 (0, 1] 上连续。
     6. (−1, 1) 是 ℝ 中开集。因此 φ₊ 是 U₊ 到 ℝ 中开集的同胚。∎
  2. 命题 B：不存在覆盖整个 S¹ 的单个 chart。（证明引用两条分析学结论，旁白中明确说出"我们借用两条分析课的事实"。）
     1. 假设存在 chart (S¹, φ)，φ : S¹ → V ⊆ ℝ^d 是同胚，V 是开集。
     2. 维数：d 只能为 1。（引用的事实：维数的不变性，即 ℝ^a 与 ℝ^b 的非空开集在 a ≠ b 时不同胚。旁白只陈述，不证明。）这一步只为确定 V ⊆ ℝ，下面的论证对任意 d 都成立。
     3. 事实 1：S¹ 在 ℝ² 中有界且闭，所以是紧集；紧集在连续映射下的像是紧集。因此 V = φ(S¹) 在 ℝ^d 中紧，从而有界且闭。
     4. 事实 2：ℝ^d 连通，其中既开又闭的子集只有 ∅ 和 ℝ^d。
     5. V 非空、既开又闭，所以 V = ℝ^d；但 V 有界，而 ℝ^d 无界，矛盾。∎
  3. 命题 C：球极投影的逆映射与验证（为 c04 的转移映射做准备）。
     1. 过 N = (0, 1) 与 (u, 0) 的直线为 t ↦ (tu, 1 − t)。
     2. 代入 x² + y² = 1：t²u² + (1 − t)² = 1 ⇒ t(t(u² + 1) − 2) = 0 ⇒ t = 2 / (u² + 1)（t = 0 对应 N 本身）。
     3. 因此 σ_N⁻¹(u) = (2u / (u² + 1), (u² − 1) / (u² + 1))。反向验证：σ_N(σ_N⁻¹(u)) = [2u / (u² + 1)] / [1 − (u² − 1) / (u² + 1)] = [2u / (u² + 1)] / [2 / (u² + 1)] = u。∎
- necessity：
  - 像必须是开集：闭上半圆 → [−1, 1] 的反例（见上）。动画说明 [−1, 1] 在端点处的邻域只有一侧，而圆上 (1, 0) 的任意小邻域两侧都有点。
  - 必须是同胚，单射不够：若坐标映射不连续，M 中相邻的点会拿到相距很远的坐标，M 中的收敛在坐标里就看不出来。回放 c01 的卷圆反例：t ↦ (cos t, sin t) 的逆 S¹ → [0, 2π) 是双射，但在 (1, 0) 处跳变，而且 [0, 2π) 也不是开集。
  - 单个 chart 不够：命题 B。直观上，把整圆压成一个开区间，必然要么撕开（不连续），要么两点重合（非单射）。动画展示整圆向 x 轴投影时每个 x ∈ (−1, 1) 对应两个点。

### c03-topological-manifold — 拓扑流形：为什么还要 Hausdorff

- question：观众能陈述拓扑流形的定义，证明 Hausdorff 空间中极限唯一，并用双原点直线解释为什么"局部欧氏"本身不够。
- requires：chart（e02-c02）、convergence（e01）。
- music：counterexample
- teaching_sequence：
  - 直觉：每一点附近都像 ℝ^d，并不能阻止整体结构出现病态。
  - 定义：d 维拓扑流形是满足以下条件的拓扑空间 M：（1）局部欧氏：每个 p ∈ M 都落在某个 d 维 chart 的定义域内；（2）Hausdorff：任意两个不同点 p ≠ q，存在不相交的开集 U ∋ p、V ∋ q；（3）第二可数：拓扑有一个可数的基。
  - 例子：S¹ 是 1 维拓扑流形。局部欧氏由 c02 的四个 chart 给出；Hausdorff 与第二可数继承自 ℝ²，因为 ℝ² 的子空间都具备这两条性质。
  - 边界：双原点直线满足局部欧氏，但不满足 Hausdorff。不可数多条实直线的不交并满足局部欧氏和 Hausdorff，但不满足第二可数。
  - 用途：优化算法生成迭代序列 x_k，我们需要"x_k 收敛到哪个点"有唯一答案。第二可数是技术性条件，本课程不展开，只说明它排除了"多得不可数"的空间。
- proof_steps：
  1. 命题：若 X 是 Hausdorff 空间，x_k → x 且 x_k → y，则 x = y。
     1. 反设 x ≠ y。由 Hausdorff，存在不相交的开集 U ∋ x、V ∋ y。
     2. 由 x_k → x（E01 的定义），存在 K₁，使 k ≥ K₁ 时 x_k ∈ U。
     3. 由 x_k → y，存在 K₂，使 k ≥ K₂ 时 x_k ∈ V。
     4. 取 k = max(K₁, K₂)，则 x_k ∈ U ∩ V = ∅，矛盾。∎
  2. 构造：双原点直线 L。
     1. 取两份实直线 ℝ × {a} 与 ℝ × {b}，把 t ≠ 0 时的 (t, a) 与 (t, b) 视为同一点，零点不粘合。得到的空间里，除了两个原点 0_a、0_b，其余点都只有一份。
     2. 拓扑：一个集合 W 是开集，当且仅当它在每一份直线中的部分都是 ℝ 中的开集（商拓扑）。于是 0_a 的开邻域都包含形如 (−ε, 0) ∪ {0_a} ∪ (0, ε) 的集合；0_b 同理。
     3. 局部欧氏：L_a = ℝ × {a} 的像是 L 中的开集，映射 t ↦ (t, a) 给出它与 ℝ 的同胚，这就是一个包含 0_a 的 chart；对 0_b 同理。其余点落在两个 chart 中的任意一个里。
     4. 不满足 Hausdorff：0_a 的任意开邻域都包含某个 (−ε, 0) ∪ (0, ε)，0_b 的任意开邻域包含某个 (−δ, 0) ∪ (0, δ)，两者至少共有 min(ε, δ)/2 这个点，所以无法分开。
     5. 极限不唯一：数列 x_k = 1/k。对 0_a 的任意开邻域，存在 ε 使 (0, ε) 在其中，k > 1/ε 时 x_k 落入，所以 x_k → 0_a；同理 x_k → 0_b。∎
  3. 补充说明（只陈述）：对 L 上任意连续函数 f，f(0_a) = lim f(1/k) = f(0_b)。连续函数无法区分两个原点，但它们确实是两个不同的点，"迭代收敛到了哪里"没有唯一答案。旁白给出这个推理：两个等号都来自"连续函数把收敛数列映成收敛数列"，而在 ℝ 中极限唯一。
- necessity：
  - 去掉 Hausdorff：双原点直线（上面的构造）。收敛序列有两个极限，优化算法的"极限点"无意义。
  - 去掉第二可数：不可数多条 ℝ 的不交并。只作陈述和示意，说明它排除"规模失控"的空间；后续课程在需要时（例如在流形上构造黎曼度量）会用到这一条。示意图标注 "schematic: uncountably many copies"。

### c04-transition-maps — 重叠区：同一个点的两套坐标

- question：观众能算出 S¹ 两个半圆 chart 在重叠区上的转移映射，以及两个球极投影之间的转移映射，并说明为什么转移映射是 ℝ^d 开集之间的普通映射。
- requires：chart（e02-c02）。
- music：definition
- teaching_sequence：
  - 直觉：两张地图都画了同一个城市，城市在两张图上的坐标不同，存在一个换算公式。
  - 定义：设 (U, φ)、(V, ψ) 是两个 chart，且 U ∩ V ≠ ∅。转移映射 ψ∘φ⁻¹ : φ(U ∩ V) → ψ(U ∩ V)。其定义域、值域都是 ℝ^d 的开集，所以可以直接用多元微积分。
  - 例子 1：U₊ = {y > 0}（坐标 x），U_r = {x > 0}（坐标 y）。重叠是第一象限的开四分之一圆弧。φ₊(U₊ ∩ U_r) = (0, 1)，φ_r(U₊ ∩ U_r) = (0, 1)，φ_r∘φ₊⁻¹(x) = √(1 − x²)。
  - 例子 2：球极投影 σ_N、σ_S 的重叠为 S¹∖{N, S}，σ_N 的像为 ℝ∖{0}，σ_S∘σ_N⁻¹(u) = 1/u。
  - 边界：转移映射只在重叠区上有定义。重叠区是开集，所以端点不包含在内。例如 √(1 − x²) 在 x → 1 时导数发散，但 x = 1 不在定义域 (0, 1) 内。
  - 用途：c05 要求转移映射光滑，这就是"光滑结构"的全部内容。
- proof_steps：
  1. 重叠区的坐标像：U₊ ∩ U_r = {(x, y) ∈ S¹ : x > 0, y > 0}。在 φ₊ 下，像为 {x : 0 < x < 1}，因为 x > 0，且 y = √(1 − x²) > 0 ⇔ x < 1。同理 φ_r 的像为 (0, 1)。
  2. 计算：对 x ∈ (0, 1)，φ₊⁻¹(x) = (x, √(1 − x²))，再取 y 分量得 φ_r(φ₊⁻¹(x)) = √(1 − x²)。
  3. 光滑性：在 (0, 1) 上 1 − x² > 0，√ 在 (0, ∞) 上是 C^∞，复合后为 C^∞，导数为 −x / √(1 − x²)。逆转移映射 φ₊∘φ_r⁻¹(y) = √(1 − y²) 同理光滑。
  4. 球极投影：由 c02 命题 C，σ_N⁻¹(u) = (2u / (u² + 1), (u² − 1) / (u² + 1))，u ≠ 0 时该点不是 S。σ_S(x, y) = x / (1 + y)，其中 1 + y = 2u² / (u² + 1)。于是 σ_S∘σ_N⁻¹(u) = [2u / (u² + 1)] · [(u² + 1) / (2u²)] = 1/u。在 ℝ∖{0} 上 C^∞，且是自身的逆。∎
- necessity：本章只建立概念；不相容的反例在 c05。边界说明：如果把重叠区闭包上的点也算进来，√(1 − x²) 在 x = 1 处不可微，可见"开集"这一要求在保护转移映射的光滑性。
- visual_events：
  - e1｜"一个点同时在两张地图上"｜S¹ 居中，上半圆 U₊（青色）、右半圆 U_r（洋红），重叠的四分之一弧为两色叠加；左下 x 轴（φ₊ 的坐标）、右侧竖直 y 轴（φ_r 的坐标）｜两段弧和两条坐标轴淡入｜无｜重叠区高亮。
  - e2｜"同一点 p 得到两个数"｜重叠区内一点 p = (0.6, 0.8)，青色竖线落到 x 轴上 0.6，洋红横线落到 y 轴上 0.8｜两条投影线同时生长｜e1 保留｜两个数字标签 0.6、0.8。
  - e3｜"把一个坐标换成另一个，就是转移映射"｜底部单独的二维坐标图：横轴 x ∈ (0, 1)，纵轴 y ∈ (0, 1)，曲线 y = √(1 − x²)｜p 沿重叠弧移动，图中对应点沿曲线同步移动｜上方圆图保留｜曲线完整画出，公式块 φ_r∘φ₊⁻¹(x) = √(1 − x²)。

### c05-why-compatibility — 为什么 chart 之间必须光滑相容

- question：观众能用 ℝ 上的两个 chart（id 与 x³）说明：如果允许不相容的 chart，"一个函数是否光滑"就没有确定的答案。观众能陈述光滑图册与极大图册的定义，并说出极大图册解决了什么问题。
- requires：transition-map（e02-c04）、euclid-calculus（受众已知）。
- music：counterexample
- teaching_sequence：
  - 直觉：我们想这样定义：f 在 M 上光滑，就是它在坐标里看起来光滑。但坐标不止一套；如果两套坐标之间的换算本身不光滑，不同的坐标会给出不同的结论。
  - 反例：M = ℝ（拓扑为通常拓扑）。chart 1 为 (ℝ, id)；chart 2 为 (ℝ, κ)，κ(p) = p³。两者都是同胚。函数 f(p) = p 在 chart 1 下坐标表示为 f∘id⁻¹(x) = x，光滑；在 chart 2 下坐标表示为 f∘κ⁻¹(u) = u^{1/3}，在 u = 0 处不可微。
  - 定义：两个 chart 光滑相容，指 U ∩ V = ∅，或者 ψ∘φ⁻¹ 与 φ∘ψ⁻¹ 都是 C^∞（即 ψ∘φ⁻¹ 是开集之间的微分同胚）。光滑图册：定义域覆盖 M、两两光滑相容的一族 chart。极大图册（光滑结构）：不能再加入任何与它相容的新 chart 的光滑图册。光滑流形 = 拓扑流形 + 一个光滑结构。
  - 例子：c02 的四半圆图册与球极投影图册都是 S¹ 上的光滑图册，而且两者的 chart 彼此相容，因此决定同一个极大图册，也就是同一个光滑结构。
  - 边界：{κ} 单独也是 ℝ 上的一个光滑图册（只有一个 chart，相容性自动成立），它决定的光滑结构与 {id} 决定的不同，因为 id 与 κ 不相容。光滑结构是一项额外选择的数据，不是拓扑自带的（c07 会看到这两个结构仍然微分同胚）。
  - 用途：c06 中光滑映射的良定义性完全依赖相容性。
- proof_steps：
  1. κ 是同胚：κ(p) = p³ 在 ℝ 上是严格单调的双射，连续；逆映射 u ↦ u^{1/3}（实立方根）连续。
  2. u^{1/3} 在 0 处不可微：差商 (h^{1/3} − 0) / h = h^{−2/3} → +∞（h → 0）。
  3. 不相容：κ∘id⁻¹(x) = x³ 光滑，但 id∘κ⁻¹(u) = u^{1/3} 不光滑，所以两个方向的转移映射不同时光滑，chart 不相容。
  4. 命题：每个光滑图册 A 都包含在唯一的极大图册中。
     1. 构造：Ā = {所有与 A 中每个 chart 都光滑相容的 chart}。显然 A ⊆ Ā。
     2. Ā 中任意两个 chart 互相相容：取 (U₁, φ₁)、(U₂, φ₂) ∈ Ā，以及 x ∈ φ₁(U₁ ∩ U₂)，令 p = φ₁⁻¹(x)。取 A 中包含 p 的 chart (W, θ)。在 φ₁(U₁ ∩ U₂ ∩ W) 这个包含 x 的开集上，φ₂∘φ₁⁻¹ = (φ₂∘θ⁻¹)∘(θ∘φ₁⁻¹)。两个因子都光滑（Ā 的定义），所以复合在 x 附近光滑。光滑是局部性质，x 任意，因此 φ₂∘φ₁⁻¹ 在整个定义域上光滑；反方向同理。
     3. 极大性：若某个 chart 与 Ā 中所有 chart 相容，则它与 A 中所有 chart 相容，所以已经在 Ā 中。
     4. 唯一性：若极大图册 B ⊇ A，则 B 的每个 chart 与 A 相容，所以 B ⊆ Ā；Ā 是光滑图册且包含 B，由 B 的极大性得 B = Ā。∎
- necessity：
  - 去掉相容性：ℝ 上 id 与 κ 的反例，同一个 f 得到相反的判定。
  - 去掉"极大"：S¹ 的四半圆图册与球极投影图册是两个不同的集合；若把"光滑流形"定义为"拓扑空间 + 某个具体图册"，同一个圆就会变成两个不同的光滑流形。极大图册把所有相容的图册归为同一个光滑结构，使定义与图册的选取无关。
- visual_events：
  - e1｜"同一条实直线，两套坐标"｜中央一条水平实直线 M（白色），上方坐标轴 x（chart id，青色），下方坐标轴 u（chart κ，橙色）；M 上 9 个等距采样点｜采样点分别向上（等距）和向下（u = p³，在 0 附近挤在一起、远处拉开）映射｜无｜两组对应线定格，下方点的疏密明显不均。
  - e2｜"两个都是同胚"｜检查清单（bijective / continuous / continuous inverse）分别对两个 chart 打勾｜打勾动画｜e1 保留｜两列勾都完成。
  - e3｜"在第一套坐标里，f 是直线"｜右上小图：f∘id⁻¹(x) = x 的图像，青色直线｜画线动画｜e1 缩到左侧｜标签 "smooth"。
  - e4｜"在第二套坐标里，f 在零点处竖直"｜右下小图：f∘κ⁻¹(u) = u^{1/3} 的图像，橙色曲线；原点处切线竖直｜画线后在原点放大，切线竖起，差商 h^{−2/3} 的数值随 h → 0 增大（显示 h = 0.1, 0.01, 0.001 三档）｜e3 保留｜标签 "not differentiable at 0"，两图并列，中间一个红色 "?"。
  - e5｜"毛病出在两套坐标的换算上"｜公式块：κ∘id⁻¹(x) = x³ ✓，id∘κ⁻¹(u) = u^{1/3} ✗｜两行依次出现，第二行红色｜两张小图保留｜定义块 "smoothly compatible: both transition maps C^∞"。
  - e6｜"光滑图册与极大图册"｜S¹ 两组图册并排：左边四色半圆，右边球极投影｜两组合并成一个大集合（示意：一个圆角框容纳更多 chart 图标，以省略号表示 "all compatible charts"）｜无｜标签 "maximal atlas = smooth structure"。
  - e7｜"极大图册中两个 chart 为什么相容"｜示意：p 附近三个重叠的开集 U₁、U₂、W，以及三个坐标平面；φ₂∘φ₁⁻¹ 的箭头被拆成经过 θ 坐标的两段｜拆分动画：一条长箭头变为两段短箭头，中间经过 θ(W)｜e6 淡出｜公式 φ₂∘φ₁⁻¹ = (φ₂∘θ⁻¹)∘(θ∘φ₁⁻¹)。

### c06-smooth-maps — 光滑映射：坐标表示与良定义性

- question：观众能写出 F̂ = ψ∘F∘φ⁻¹，完整证明"F 是否光滑"不依赖于所选的相容 chart，并在 S¹ 的高度函数上验证两个 chart 给出一致的结论。
- requires：smooth-compatibility（e02-c05）、continuity（e01）、euclid-calculus（受众已知）。
- music：proof
- teaching_sequence：
  - 直觉：先把 F 搬进坐标里，再在坐标里判断光滑性；相容性保证换一套坐标时结论不变。
  - 定义：M、N 分别是 m 维、n 维光滑流形，F : M → N 连续。称 F 光滑，若对每个 p ∈ M，存在 chart (U, φ) ∋ p 和 (V, ψ) ∋ F(p)，满足 F(U) ⊆ V，且坐标表示 F̂ = ψ∘F∘φ⁻¹ : φ(U) → ψ(V) 在欧氏意义下 C^∞。
  - 例子：高度函数 F : S¹ → ℝ，F(x, y) = y，ℝ 取 chart id。在 φ₊ 下，F̂(x) = √(1 − x²)，x ∈ (−1, 1)，光滑。在 φ_r 下，F̂(y) = y，y ∈ (−1, 1)，光滑。重叠区上两种结论一致。
  - 边界：要求 F 连续，是为了能把 U 缩小到满足 F(U) ⊆ V：取 U ∩ F⁻¹(V)，由 F 连续知它仍是开集。
  - 用途：Riemannian optimization 中的目标函数 f : M → ℝ 就是一个光滑映射；"f 光滑"的含义正是本章的定义。
- proof_steps：
  1. 设定：设 F 在 p 附近关于 (U, φ)、(V, ψ) 光滑，即 F(U) ⊆ V 且 ψ∘F∘φ⁻¹ 在 φ(U) 上 C^∞。另取极大图册中的任意 chart (U′, φ′) ∋ p、(V′, ψ′) ∋ F(p)。
  2. 公共定义域：令 W = U ∩ U′ ∩ F⁻¹(V ∩ V′)。U ∩ U′ 是开集；F 连续且 V ∩ V′ 开，所以 F⁻¹(V ∩ V′) 是开集；W 是开集且 p ∈ W。于是 φ′(W) 是 ℝ^m 中包含 φ′(p) 的开集。
  3. 拆分：对 x ∈ φ′(W)，φ′⁻¹(x) ∈ W ⊆ U，所以可以插入 φ⁻¹∘φ = id_U；又 F(φ′⁻¹(x)) ∈ V ∩ V′，可以插入 ψ⁻¹∘ψ = id_V：
     ψ′∘F∘φ′⁻¹ = (ψ′∘ψ⁻¹)∘(ψ∘F∘φ⁻¹)∘(φ∘φ′⁻¹)，在 φ′(W) 上成立。
  4. 三个因子都光滑：φ∘φ′⁻¹ : φ′(U ∩ U′) → φ(U ∩ U′) 是转移映射，由相容性 C^∞；ψ∘F∘φ⁻¹ 由假设 C^∞；ψ′∘ψ⁻¹ : ψ(V ∩ V′) → ψ′(V ∩ V′) 是转移映射，由相容性 C^∞。
  5. 欧氏开集之间 C^∞ 映射的复合仍是 C^∞（链式法则逐阶应用）。所以 ψ′∘F∘φ′⁻¹ 在 φ′(p) 附近 C^∞。∎
  6. 推论：光滑映射的复合仍光滑。G∘F 的坐标表示为 (χ∘G∘ψ⁻¹)∘(ψ∘F∘φ⁻¹)，是两个 C^∞ 映射的复合。
- necessity：
  - 若 chart 不相容，第 4 步的转移映射因子可能不光滑，证明在此断开。回到 c05：把 M = ℝ 上的 chart 从 id 换成 κ，因子 id∘κ⁻¹ = u^{1/3} 正是坏掉的那一环，同一个 f(p) = p 的判定由"光滑"翻转为"不光滑"。
  - 若 F 不连续，F⁻¹(V ∩ V′) 可能不是开集，第 2 步的公共定义域不再是开集，"在 φ′(p) 附近光滑"无从谈起。
- visual_events：
  - e1｜"把映射搬进坐标里"｜左侧一个弯曲的二维曲面块 M 与其中的开集 U、点 p；右侧另一曲面块 N 与 V、F(p)；下方两个坐标平面 φ(U) ⊆ ℝ^m、ψ(V) ⊆ ℝ^n｜四个对象与 F、φ、ψ 三条箭头依次出现，最后底部出现虚线箭头 F̂ = ψ∘F∘φ⁻¹｜无｜交换图完整，F̂ 箭头高亮。

### c07-diffeomorphism — 微分同胚：比同胚更强的"相同"

- question：观众能陈述微分同胚的定义，证明 x³ : ℝ → ℝ 是同胚但不是微分同胚，并填出"拓扑 ↔ 光滑"的对照表。
- requires：smooth-map（e02-c06）、homeomorphism（e01）。
- music：counterexample
- teaching_sequence：
  - 直觉：同胚允许把空间揉皱，只要不撕裂、不粘连；微分同胚还要求揉的过程在两个方向上都光滑，不能出现折痕或尖点。
  - 定义：F : M → N 是微分同胚，若 F 是双射、F 光滑、F⁻¹ 光滑。
  - 例子（反例）：ℝ 取标准光滑结构，F(x) = x³ 是光滑双射，其逆 x^{1/3} 连续，所以 F 是同胚；但 F⁻¹ 在 0 处不可微，所以 F 不是微分同胚。
  - 例子（正例，回应 c05 的边界）：把 F = κ 看成映射 (ℝ, {κ}) → (ℝ, {id})，它是微分同胚。坐标表示 id∘κ∘κ⁻¹(u) = u，逆的坐标表示 κ∘κ⁻¹∘id⁻¹(x) = x，两者都光滑。所以 c05 中两个不同的光滑结构彼此微分同胚：结构不同，但作为光滑流形"本质相同"。
  - 边界：微分同胚要求逆光滑，"光滑双射"并不足够，x³ 就是反例。F′(0) = 0 时 F 在 0 处把所有方向压扁，逆映射只能是无限陡峭的。这预告 E03：反函数定理断言，导数可逆时局部逆一定光滑。
  - 用途：在优化中做变量替换（重新参数化）时，若替换是微分同胚，则 f 在 N 上光滑 ⇔ f∘F 在 M 上光滑，光滑性完整保留。
- proof_steps：
  1. F(x) = x³ 光滑：多项式，C^∞。
  2. 双射：严格单调递增（x₁ < x₂ ⇒ x₁³ < x₂³），且值域为 ℝ（连续，x → ±∞ 时 x³ → ±∞，由介值定理得满射）。
  3. F⁻¹(y) = y^{1/3} 连续，所以 F 是同胚。
  4. F⁻¹ 在 0 处不可微：(F⁻¹(h) − F⁻¹(0)) / h = h^{−2/3} → +∞。所以 F⁻¹ 不光滑，F 不是微分同胚。∎
  5. 联系导数：若 F 是微分同胚，对 F⁻¹∘F = id 求导，由链式法则 (F⁻¹)′(F(x)) · F′(x) = 1，所以 F′(x) ≠ 0。而 x³ 在 0 处 F′(0) = 0，这条必要条件不满足，从另一个角度说明 F 不可能是微分同胚。∎
  6. 变量替换保持光滑性：若 F : M → N 是微分同胚、f : N → ℝ 光滑，则 f∘F 光滑（光滑映射的复合，c06 推论）；反之若 f∘F 光滑，则 f = (f∘F)∘F⁻¹ 光滑。∎
- necessity：
  - 去掉"F⁻¹ 光滑"：x³ 反例。光滑双射可以有不光滑的逆。
  - 第 5 步说明，"导数处处非零"是成为微分同胚的必要条件。E03 将证明它在局部也是充分的（反函数定理）。
- visual_events：
  - e1｜"拓扑意义下的相同与光滑意义下的相同"｜左右两栏对照表（初始只有表头）：topological spaces ↔ smooth manifolds｜表头出现｜无｜空表待填。
  - e2｜"x³ 是光滑双射"｜坐标图 y = x³（青色曲线），网格；横轴上一组等距刻度点经 F 映到纵轴｜点逐个映射，纵轴上的像在 0 附近挤在一起｜e1 缩到上方｜曲线完整。
  - e3｜"它的逆是 x^{1/3}"｜同一坐标系中关于 y = x 镜像出 y = x^{1/3}（橙色）｜镜像翻转动画｜青色曲线保留｜两条曲线并存。
  - e4｜"逆在零点处竖直"｜放大镜聚焦原点；橙色曲线在原点的切线逐渐竖直；数值框 h = 0.1 → 0.01 → 0.001，对应差商 4.6 → 21.5 → 100（h^{−2/3}）｜数值逐档显示｜e3 保留｜标签 "F⁻¹ not differentiable at 0"。
  - e5｜"根源：F′(0) = 0，一个方向被压扁"｜原点处一个小线段（长度 2ε）经 F 映为长度 2ε³ 的线段，以比例尺显示收缩｜线段收缩动画｜e4 放大镜保留｜公式 (F⁻¹)′(F(x)) · F′(x) = 1 ⇒ F′(x) ≠ 0，红色标注 "fails at 0"。
  - e6｜"填表"｜对照表填入两行：homeomorphism ↔ diffeomorphism；continuous map ↔ smooth map；以及第三行：open subsets of ℝ^d (charts) ↔ compatible charts (smooth atlas)｜逐行出现｜无｜完整对照表。

### c08-intrinsic-vs-extrinsic — 内蕴与外蕴：为什么需要"由方程生成 chart"

- question：观众能说出内蕴定义与外蕴（方程）描述的区别；能数出 O(n) 的变量个数、方程个数和预期维数；能解释为什么手工构造 O(n) 的 chart 不可行，从而需要 E03/E04 的定理。
- requires：chart（e02-c02）、smooth-compatibility（e02-c05）、smooth-map（e02-c06）。
- music：motivation
- teaching_sequence：
  - 直觉：内蕴定义像"只给你一叠地图和换算表"，不提到地球之外的任何东西；外蕴描述像"告诉你地球是三维空间中满足 ‖x‖ = 1 的点"。
  - 定义：内蕴视角：流形 = 拓扑空间 + 极大光滑图册，不需要外部空间。外蕴视角：M = {x ∈ ℝⁿ : h(x) = c}，由定义方程给出。
  - 例子 1：S² = {x ∈ ℝ³ : ‖x‖² = 1}。可以手工给出 6 个半球 chart，每个都是"解出一个坐标"：例如上半球 z = √(1 − x² − y²)，chart 为 (x, y, z) ↦ (x, y)。
  - 例子 2：O(n) = {R ∈ ℝ^{n×n} : RᵀR = I}。变量 n² 个。RᵀR 是对称矩阵，所以独立方程只有 n(n + 1)/2 个。预期维数为 n² − n(n + 1)/2 = n(n − 1)/2。n = 3 时：9 个变量，6 个方程，预期维数 3。
  - 关键观察：c02 的半圆 chart 正是"从方程 x² + y² = 1 中解出 y = √(1 − x²)"。半圆 chart 只在 ∂/∂y (x² + y² − 1) = 2y ≠ 0 的地方可用：在 (±1, 0) 处无法解出 y，只能改为解出 x。
  - 边界：对 O(3)，应该从 9 个元素中选哪 6 个来解出？解出的表达式怎么写？如何保证覆盖整个 O(3)，并且转移映射光滑？手工做不下去。熟悉的参数化，比如欧拉角，在某些姿态处退化（万向节锁），一组角度无法作为全局 chart。
  - 用途：引出 E03 的反函数定理和 E04 的隐函数定理、正则水平集定理：只要检查导数的秩，就能保证 chart 存在，并给出局部构造方法，不必猜测。
- proof_steps：
  1. 方程计数：RᵀR 的 (i, j) 元为 rᵢᵀr_j（rᵢ 为第 i 列），满足 rᵢᵀr_j = r_jᵀrᵢ，所以 (i, j) 与 (j, i) 是同一个方程。独立方程对应 i ≤ j 的位置：对角线 n 个，严格上三角 n(n − 1)/2 个，合计 n(n + 1)/2。
  2. 预期维数：n² − n(n + 1)/2 = (2n² − n² − n)/2 = n(n − 1)/2。n = 2 时为 1（平面旋转的一个角度）；n = 3 时为 3。
  3. 说明（陈述，不在本集证明）："变量数 − 独立方程数 = 维数"只是预期，需要条件才成立。何时成立、如何构造 chart，正是 E04 正则水平集定理的内容。本集只计数，不下结论。
- necessity：
  - 圆的例子显示"解出某个坐标"会在某些点失败（(±1, 0) 处 2y = 0），必须换一个变量来解。这预告了 E04 中"偏导数块可逆"的条件。
  - 欧拉角退化（陈述，补充内容）：以 ZXZ 欧拉角为例，当中间角为 0 时，两个外角只通过其和起作用，三个参数实际只控制两个自由度，映射不再是局部同胚。这说明单个"方便的"参数化不能充当 chart。旁白标明这是补充示例，只演示现象。
- visual_events：
  - e1｜"两种看流形的方式"｜左：漂浮的球面 S²（无坐标轴，标 "intrinsic: charts + transition maps"），旁边两张小地图卡片；右：同一个球面置于 ℝ³ 坐标轴中（标 "extrinsic: ‖x‖² = 1"）｜两侧依次淡入，右侧坐标轴从原点生长｜无｜左右对照定格。
  - e2｜"半圆 chart 其实就是解方程"｜切换到二维：圆 x² + y² = 1，上半弧高亮，旁边公式 y = √(1 − x²)；在 (±1, 0) 处画竖直切线｜一点沿上半弧移向 (1, 0)，切线逐渐竖直，公式旁标出 2y → 0｜e1 缩小到左上角｜标签 "cannot solve for y here → solve for x"，右半弧随之以 x = √(1 − y²) 高亮。
  - e3｜"球面：六个半球，每个解出一个坐标"｜三维球面上依次高亮 6 个开半球（±x、±y、±z），每个半球投影到对应的坐标平面圆盘｜6 个半球依次出现，各自投影｜无｜六色覆盖整个球面。
  - e4｜"对 O(n)，这样做行得通吗？"｜一个 3×3 矩阵网格 R（9 个格子），旁边方程 RᵀR = I｜矩阵 RᵀR 的 9 个元素中，上三角（含对角线）6 个格子亮起，下三角 3 个格子以虚线连到其对称位置｜e3 淡出｜计数块：9 variables − 6 equations = 3。
  - e5｜"该解出哪 6 个？表达式是什么？"｜矩阵格子中随机选择的 6 格依次闪烁（固定种子的序列），每次旁边出现问号｜闪烁序列｜计数块保留｜三个问题列表（which variables? explicit formula? cover everything with smooth transitions?）。
  - e6｜"熟悉的欧拉角也会失效"｜一个三维坐标框架（三色轴）按 ZXZ 欧拉角旋转；中间角滑向 0 时，第一、第三个旋转轴重合｜两个转轴箭头逐渐重叠，变为同一条线并闪烁｜问题列表缩到右侧｜标签 "two angles control one motion"，备注 "supplementary illustration"。
